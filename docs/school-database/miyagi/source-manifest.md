# 宮城県学校データ 原本管理表

更新日: 2026-07-25
作業ブランチ: `feature/school-database-miyagi-phase1`
原本保存先: `data-source/miyagi/2025/`（Git管理外、ローカル作業用）

## 収録対象

福島県版と同じ方針で、次を収録する。

- 私立幼稚園（公立幼稚園は仙台市立のみ確認できたため公立幼稚園は仙台市立の
  1園のみ収録。他市町村の公立幼稚園の公式名簿は確認できなかった）
- 国立・公立（県立・市町村立・仙台市立）・私立小学校
- 国立・公立（同上）・私立中学校
- 公立義務教育学校
- 公立（県立・仙台市立）・私立高等学校
- 公立（仙台市立）中等教育学校
- 国立・公立（県立・仙台市立）・私立特別支援学校

専修学校・各種学校・大学・短期大学は対象外（既存都道府県版と同じ除外方針）。

## 原本形式: 県はHTMLページに直接掲載、私立はPDF

福島県版はPDF/CSVが中心だったが、宮城県教育委員会は市町村立（仙台市立を除く）
小学校・中学校・義務教育学校・高等学校・特別支援学校の名簿をダウンロード
ファイルではなく、HTMLページ上のテーブルとして直接掲載している。仙台市立学校
（小中学校は区ごと、高校・中等教育学校・幼稚園・特別支援学校は別ページ）も
同様にHTMLテーブル。私立学校（幼稚園・小中高・特別支援）のみ、1ファイル26ページの
PDF（原本の基準日は公立より1年古い令和7年5月1日）。

`convert_miyagi_workbooks.py` は BeautifulSoup（HTMLテーブル抽出）と
pdfplumber（PDF表抽出）を組み合わせて実装している。

## 県公式ページ（小学校・中学校・義務教育学校、仙台市立を除く、基準日 令和7年5月1日）

| ページ | URL | 内容 |
| :--- | :--- | :--- |
| es.html | https://www.pref.miyagi.jp/site/kyouiku/es.html | 公立小学校 |
| lss.html | https://www.pref.miyagi.jp/site/kyouiku/lss.html | 公立中学校 |
| lss2.html | https://www.pref.miyagi.jp/site/kyouiku/lss2.html | 公立義務教育学校 |

いずれも[所在地(市町村), 学校名(ふりがな), 電話番号, 郵便番号, 住所]の5列表。
市町村列はHTMLの`rowspan`属性で結合されており、同じ市町村が続く行は
4セルしか持たない（1セル目から既に学校名）点に注意が必要。学校名セルには
「村田町立村田小学校(むらたちょうりつむらたしょうがっこう)」のように
ふりがなが括弧書きで併記されており、`name_kana`として収録した。

## 県公式ページ（高等学校・特別支援学校）: koukou.html

出典: https://www.pref.miyagi.jp/site/kyouiku/koukou.html（基準日 令和7年5月1日）

3つのテーブルで構成される。

- table0（86行）: 県立高等学校（学区列がrowspan結合）。ただし仙台市立高校
  （仙台工業・仙台商業・仙台大志の各高等学校）も名前に「宮城県」を冠さずに
  同じ表に混在しており、仙台市教育委員会の公式ページと重複するため、
  校名が「宮城県」で始まらない行は除外した。
- table1（2行）: 市立学校名（仙台青陵中等教育学校1件のみ）。仙台市の公式ページと
  重複するため未使用。
- table2（32行）: 国立→県立→市立の順で1つの表に混在する特別支援学校一覧。
  見出し行の文言がそれぞれ「国立学校名」「県立学校名」「市立学校名」と
  設置区分そのものを表しており（「特別支援学校名」という共通見出しではない点に
  注意）、市立分は仙台市の公式ページと重複するため除外した。

## 仙台市立学校（PDFではなくHTMLページ、令和8年7月13日時点のページ内容）

出典: https://www.city.sendai.jp/shogakuchose/kurashi/manabu/kyoiku/inkai/kanren/shiritsu/

| ページ | 内容 |
| :--- | :--- |
| aobaku-02 / miyagino-02 / wakabayashi-03 / taihaku-04 / izumi-03 | 区ごとの市立小・中学校所在地一覧（各2テーブル: table0=小学校, table1=中学校） |
| koukou_chuto_turutoku_youtien | 市立高等学校・中等教育学校・幼稚園・特別支援学校（固定順4テーブル） |

区ページの電話番号は市外局番（022）が省略されているため、変換時に補完した。
青葉区ページには東北大学病院内に設置された分校が「同東北大学病院分校」
（「同」は原本の省略表記）とだけ記載されており、親校名を機械的に復元できない
ため、東北大学病院公式サイト（https://www.hosp.tohoku.ac.jp/hospitalization/006.html ）
で確認した正式名称「仙台市立木町通小学校東北大学病院分校」
「仙台市立第二中学校東北大学病院分校」を個別に対応した。

## 私立学校名簿PDF（1ファイル26ページ、基準日 令和7年5月1日）

出典: https://www.pref.miyagi.jp/documents/6697/r7_meibo.pdf

| ページ | 内容 |
| :--- | :--- |
| 6ページ目 | 高等学校・特別支援学校（全日制/通信制/特別支援学校の3カテゴリが1表に混在） |
| 7ページ目 | 中学校・小学校（2カテゴリが1表に混在） |
| 8〜11ページ目 | 幼稚園（市町村見出し＋休園見出し以降を除外） |

カテゴリ見出し行は「学科」列ではなく「番号」列（先頭セル）にカテゴリ名
（全日制/通信制/特別支援学校、中学校/小学校）がそのまま入り、残りの列は全て
空という特殊な構造になっている。学校によっては全日制・通信制の両方に
同一名称・住所・電話番号で掲載されている（例: 東陵高等学校、東北生活文化大学
高等学校）ため、変換時に同一校を1レコードへ統合し`course`へ両方の値を
保持した。

幼稚園ページは番号・園名・設置者・園長・定員・郵便番号・所在地・電話番号の
列を持ち、市町村見出し行と「休園」見出し行（以降の6件を除外）がある。
除外件数は原本冒頭の「私立学校数一覧」統計（幼稚園135園中6園休園）と一致する
ことを確認済み。

## 品質基準（既存都道府県版を継承）

- 学校名、住所、郵便番号、電話番号は推測で補わない。
- 電話番号は市外局番＋市内局番＋番号の形式に正規化する。義務教育学校で
  「前期課程(小)0229(26)2327後期課程(中)0229(26)2114」のように前期・後期課程の
  電話番号が区切りなく併記されている場合は「0229-26-2327 / 0229-26-2114」形式
  （千葉県版の複数電話番号表記と同じ形式）で保持する。
- 休校・休園中と原本に明記された学校は公開対象から除外する。
- 公式HP（website）は、今回の初期変換では確実に判定できるものがないため全件空欄。
- 基本検証（`validate_school_data.py`）は0件エラー・1件警告（上記の複数電話番号の
  形式確認）で合格。
