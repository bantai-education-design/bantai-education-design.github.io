# 都道府県別 人口・教育統計 出典マニフェスト

本ドキュメントは、全国学校データベースの各都道府県カードに表示する人口および教育統計のデータ出典と加工ルールを定義するものです。

## 1. 人口統計（総人口・年齢各歳別人口）

- **使用した統計名**: 令和2年国勢調査 人口等基本集計
- **提供機関**: 総務省統計局
- **統計表番号**: 2-1-1 男女，年齢（各歳），国籍総数か日本人別人口－全国，都道府県
- **対象年**: 令和2年（2020年）
- **基準日**: 2020年10月1日
- **URL**: [e-Stat 令和2年国勢調査](https://www.e-stat.go.jp/stat-search/database?stat-name=%E5%9B%BD%E5%8B%A2%E8%AA%BF%E6%9F%BB&page=1&layout=dataset&toukei=00200521&tstat=000001080615&cycle=0&tclass1=000001136464&tclass2=000001136465&tclass3=000001136466&second-item-1=000001136474)
- **ファイル形式**: CSV形式（e-Statからのダウンロード）
- **年齢区分**: 1歳刻み（各歳）
- **男女区分**: 総数・男・女

## 2. 教育統計（在学者数）

- **使用した統計名**: 令和5年度 学校基本調査
- **提供機関**: 文部科学省
- **統計表番号**: 初等中等教育機関、専修学校・各種学校編（都道府県別 在学者数）
- **対象年**: 令和5年（2023年）
- **基準日**: 2023年5月1日
- **URL**: [e-Stat 学校基本調査](https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&toukei=00400001&tstat=000001011528&cycle=1&year=20230&month=0)
- **ファイル形式**: Excel/CSV形式

## 3. データ加工・算出ルール

### 年齢別区分の定義（学齢相当人口）
国勢調査の「年齢（各歳）」データを元に、以下の区分で総数および男女別人口を集計しています。

- **幼児・就学前年代（3～5歳）**: 3歳、4歳、5歳の合算
- **小学校年代（6～11歳）**: 6歳から11歳の合算
- **中学校年代（12～14歳）**: 12歳から14歳の合算
- **高校年代（15～17歳）**: 15歳から17歳の合算

### 割合の計算式
カードに表示する「義務教育年代人口割合」は、以下の式で算出しています。
- **義務教育年代人口** ＝ 6～11歳人口 ＋ 12～14歳人口
- **義務教育年代人口割合** ＝ （義務教育年代人口 ÷ 総人口） × 100
- **端数処理**: 小数点第2位を四捨五入し、小数点第1位まで表示。

### 都道府県間比較の注意点
- 人口データ（令和2年）と在学者数データ（令和5年）で基準年が3年異なっています。これは、都道府県別の1歳刻み人口データが国勢調査（5年ごと）でしか公表されていないためです。画面上では注記を明記して対応しています。
- 「在学者数」は実際の学校在籍者数であり、「年齢別人口（学齢相当人口）」とは一致しません（越境通学、特別支援学校在籍、通信制、高校進学率等の影響を含むため）。

## 4. 欠損値およびゼロの扱い
- 取得できない項目（特定の学校種が存在しないなど）は `null` として扱い、UI上では「-」や非表示として処理しています。
- `null` を `0` として扱うことはせず、厳密に区別しています。
