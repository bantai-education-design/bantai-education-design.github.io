# 千葉県 令和8年度新設・改編校 調査記録

更新日: 2026-07-24
対象: 令和7→8年度の変更一覧（`r8-gakkouichiran-2_henkou_ichiran.xls`）で新設・改編と確認された4校
関連: [source-manifest.md](source-manifest.md) / [conversion-plan.md](conversion-plan.md) / `tools/school-database/chiba_overrides.json`

## 調査方針

使用した資料は次に限定した。

- 市町村・教育委員会の公式サイト（館山市役所公式サイト）
- 学校公式ホームページ
- 千葉県教育委員会「公立学校一覧（令和7→8年度変更一覧）」（既存の一次資料）
- 日本郵便 郵便番号検索（八千代市の郵便番号確認のみ使用、確定には至らず）

Wikipedia、民間学校検索サイト、地図検索結果のみの情報、不動産サイト、電話帳サイトは使用していない。教育委員会の代表番号しか確認できない学校電話番号は登録していない。

## 4. 八千代市立みどりが丘第二小学校

```text
学校名: 八千代市立みどりが丘第二小学校
設置日: 令和8年4月1日（みどりが丘小学校の分離新設校として開校、令和8年5月15日開校式）
郵便番号: 未確認（空欄で確定）

電話番号: 未確認（空欄で確定）
公式HP: 未確認（空欄で確定）
調査した公式資料:
  - 千葉県教育委員会「公立学校一覧（令和7→8年度変更一覧）」（学校名・所在地の根拠として使用）
    https://www.pref.chiba.lg.jp/kyouiku/seisaku/kouhou/gakkou-ichiran/documents/r8-gakkouichiran-2.xls
  - 八千代市公式サイト「（仮称）みどりが丘小学校分離新設校設立準備委員会」ページ
    （開校準備委員会の会議記録のみで、学校自体の郵便番号・電話番号・HP情報は掲載なし）
    https://www.city.yachiyo.lg.jp/soshiki/57/53856.html
  - 日本郵便 郵便番号検索（千葉県八千代市）
    https://www.post.japanpost.jp/cgi-zip/zipcode.php?pref=12&city=1122210
接続できなかった公式サイト:
  - 八千代市教育委員会公式サイト（https://www.yachiyo.ed.jp/ 以下の全ページ）
    今回の作業環境からブラウザーツール・WebFetchのいずれでも接続拒否（ECONNREFUSED等）となり、
    学校一覧ページ（.../sosiki/gakumu/gakkouitiran/）を含め内容を確認できなかった。
郵便番号を確定できなかった理由:
  日本郵便の郵便番号検索で「千葉県八千代市」を照会したところ、大和田新田は
  「大和田新田（その他）276-0046」「大和田新田（高津団地）276-0035」の2区分に分かれており、
  該当校の番地「1100-1」がどちらの区分に属するかを公式データのみから確定できなかったため。
  推測での登録は行わず空欄とした。
電話番号を登録しなかった理由:
  学校自体の電話番号を掲載した公式ページ（学校公式HPまたは市教育委員会の学校一覧）に
  接続できなかったため。八千代市教育委員会学務課学事班の代表電話（047-481-0302）は確認できたが、
  学校専用の番号ではなく教育委員会の代表番号であるため、学校電話番号としては登録していない。
公式HPを空欄とした理由:
  学校専用の公式ホームページURLを確認できる公式ページ（教育委員会の学校一覧等）に
  接続できなかったため。他校（館山市の3校）で使用したCanva等の個別URLも本校では確認できていない。
最終確認日: 2026-07-24
備考:
  追加確認が必要。今後、学校公式サイトまたは八千代市教育委員会の学校一覧ページへの
  アクセスが可能になり次第、郵便番号・電話番号・公式HPを確認し `chiba_overrides.json` へ追記する。
```

## chiba.json との整合性

`chiba_overrides.json` に登録した3校（館山市の2校+分校）の値は、上記調査記録の値と完全に一致する。
`tools/school-database/convert_chiba_workbooks.py` 実行時に `apply_overrides()` がこのファイルを
読み込み、該当レコードへ反映する。八千代市立みどりが丘第二小学校は補正データを登録していないため、
`chiba.json` 上は郵便番号・電話番号・公式HPが空欄のまま残る（意図した状態）。
