# 大阪府学校データ 原本管理表

更新日: 2026-07-28
作業ブランチ: `feature/school-database-osaka`
原本保存先: `data-source/osaka/`（Git管理外、ローカル作業用）

## 収録対象

既存都道府県版と同じ方針で、次を収録する。

- 国立・公立（市町村立）・私立幼稚園
- 私立幼保連携型認定こども園（公立は確認できず0件）
- 国立・公立（市町村立）・私立小学校
- 国立・公立（市町村立）・私立中学校
- 公立（市町村立）義務教育学校
- 国立・公立（府立）・私立高等学校
- 国立・公立（府立）特別支援学校

中等教育学校は大阪府内に該当校が確認できなかった（私立中等教育学校は
「認可されている私立中等教育学校はありません」と大阪府公式ページに明記）
ため0件。専修学校・各種学校・大学・短期大学は対象外。

## 公立小学校・中学校・義務教育学校: 単一PDF（罫線表）

出典: https://www.pref.osaka.lg.jp/o180080/shochugakko/jyuusho/index.html
（令和8年度版、小学校・中学校・義務教育学校それぞれ別PDF）

- 公立小学校所在地一覧（19ページ、944件）
- 公立中学校所在地一覧（9ページ、453件）
- 公立義務教育学校所在地一覧（1ページ、18件）

いずれも[市町村名, №, 学校名, 〒, 所在地, 電話番号]の罫線付き表で、
pdfplumberの`extract_tables()`でそのまま読み取れる。

### 市町村名列の注意点（大阪市の扱い）

大阪市に属する学校の行は、PDF上では「市町村名」列に大阪市を表す文字列が
セルとして存在せず、縦書きの見出しとして描画されているため
`extract_tables()`では当該列が全行`None`になる。北海道・岩手県などの
「同じ市町村が続く行はセルが省略される」現象とは異なり、そもそも
セルとして認識されない点に注意が必要。またページの境界では「市町村名」列に
直前ページ末尾の市町村名と次ページの見出し文言「市町村名」が結合して
入り込む場合があり、これをそのまま使うと「箕面市市町村名立」のような
誤った学校名が生成される。

これらの問題を避けるため、本変換では「市町村名」列を使用せず、所在地
（住所）列の先頭から市町村名を都度抽出する方式に統一した
（`_municipality_from_address`）。大阪市・堺市は「大阪市○○区」
「堺市○○区」の区単位まで抽出し、`municipality`フィールドで区ごとの
絞り込みができるようにしている。ただし正式名称の設置者部分（「○○市立」）
は区ではなく市そのものを使う（例:「大阪市立」であり
「大阪市○○区立」ではない）。

義務教育学校のうち東大阪市の2校は前期課程・後期課程で所在地・電話番号が
異なる（別キャンパス）ため、住所は最初に記載された方を採用し、電話番号は
「/」区切りで両方を保持した。

### 既知の限界: 弘済小学校・弘済中学校（本来は大阪市立）

「弘済小学校」「弘済中学校」（および高槻市の「弘済小学校分校」
「弘済中学校分校」）は、原本PDF上では大阪市の項目内に掲載されているが、
校舎の所在地はそれぞれ吹田市・高槻市にある（病弱児対象の分教室的な位置づけ）。
本変換では市町村名を住所から機械的に抽出する方式に統一した結果、これら
4件は正式名称が「吹田市立弘済小学校」「高槻市立弘済中学校」
「高槻市立弘済小学校分校」「高槻市立弘済中学校分校」となっており、
実際の設置者である「大阪市立」とは異なる。件数として2087件中4件と
影響は極めて限定的だが、既知の事実として記録する。

## 公立高等学校・支援学校: 大阪府庁サイトに一覧PDFなし → ERABO個別収集

大阪府庁サイト（`kotogakko/hp/`配下）には府立高等学校・支援学校の
ホームページへのリンク一覧はあるが、住所・電話番号を含む一括ダウンロード
資料が存在しない。そのため、大阪府教育委員会が運営する学校検索サイト
「ERABO（学校navi）」（https://www.schoolnavi.osaka-c.ed.jp/school/<ID>）
の個別学校ページをID 001〜230の範囲で機械的に取得し（有効なIDは173件）、
郵便番号・住所・電話番号・課程（全日制/定時制/通信制）を抽出した。

通信制のみの「大阪府立桃谷高等学校」はERABOに掲載がないため、学校公式
サイト（https://www.osaka-c.ed.jp/momodani/）から個別に補完した。

（当初は各校の公式サイトを地区別ページ経由で個別に巡回する方式で収集を
開始したが、ERABOという単一の公式データベースが存在することが判明したため、
より一貫性のあるERABO方式に切り替えた。）

出典:

- 私立中学校の一覧: https://www.pref.osaka.lg.jp/o180160/shigaku/syoutyuukou/itiran-chugaku.html （59件、男子校/女子校/共学校の3表）
- 私立高等学校の一覧: https://www.pref.osaka.lg.jp/o180160/shigaku/syoutyuukou/itiran-koukou.html （107件、全日制94件+通信制13件、男子校/女子校/共学校等の複数表）

直接掲載されており、BeautifulSoupで抽出した。

## 私立幼稚園・幼保連携型認定こども園: 単一PDF（罫線表）

出典: https://www.pref.osaka.lg.jp/o180160/shigaku/youchien/youchienichiran.html
（令和8年度版、304件）

管理番号・類型（私学助成/施設型給付/幼稚園型）・園名・かな・郵便番号・
所在地・電話番号・設置者名・市町村名などの列を持つ罫線表。「幼稚園型」
類型の園名列には「幼稚園型認定こども園」という類型ラベルが園名文字列の
先頭に連結されている場合があり、正式名称化の際に除去した。

## 国立学校: 大阪教育大学附属学校園（大学公式サイト記載）

大阪教育大学の附属幼稚園・小学校3校・中学校3校・高等学校3校舎・
特別支援学校の計11校園を、大学公式サイトの記載住所・電話番号から
直接収録した。高等学校の天王寺校舎・池田校舎・平野校舎は、実務上
別々の校舎として生徒募集・所在地が独立しているため、それぞれ1件の
レコードとして収録している。

## 学校名の正式名称化について

既存都道府県版と同様、原本の名簿は校種を表す接尾辞や設置者（市町村立）
表記が省略されていることが多く、`build_official_name()`で
`{設置者}立{校名}{校種}`の形式に組み立てて正式名称化している。
府立高等学校・支援学校（ERABO）分は取得元がすでに正式名称形式
（「大阪府立○○高等学校」）で掲載されているため、そのまま収録した。

## 品質基準（既存都道府県版を継承）

- 学校名、住所、郵便番号、電話番号は推測で補わない。
- 電話番号は市外局番＋市内局番＋番号の形式に正規化する。義務教育学校で
  前期課程・後期課程の電話番号が別々に記載されている場合は「/」区切りで
  両方を保持する。
- 基本検証（`validate_school_data.py --prefecture 大阪府`）は総件数2,087件、
  エラー0件・警告4件（上記の複数電話番号表記の確認のみ）で合格。

## 既知の残課題

- 「弘済小学校」「弘済中学校」（および高槻市分校）4件は、実際の設置者
  「大阪市立」ではなく、校舎所在地の市（吹田市・高槻市）を設置者として
  正式名称化している（詳細は上記）。
- 公立小・中学校にはかな読み（`name_kana`）が原本に含まれていないため
  全件空欄。私立幼稚園・府立高校/支援学校（ERABO）分のみかな読みを収録。
