# 東京都 人口メタデータ試験実装 ソースレビュー

## 目的

全国学校データベースの都道府県カードに、都道府県ごとの総人口、校種相当年齢人口、総人口に占める割合を追加できるかを確認するため、東京都のみを対象に試験実装した。

## 採用資料

- 資料名: 住民基本台帳による東京都の世帯と人口 令和8年1月 第6表 区市町村、年齢（各歳）及び男女別日本人人口
- 発行者: 東京都総務局統計部
- 基準日: 2026年1月1日
- データ定義: 住民基本台帳に記載された日本人人口
- ページ: https://www.toukei.metro.tokyo.lg.jp/juukiy/2026/jy26q10601.htm
- CSV: https://www.toukei.metro.tokyo.lg.jp/juukiy/2026/jy26qv0600.csv
- 取得日: 2026年7月31日

東京都公式サイトの当該ページは、令和8年1月1日現在で住民基本台帳に記載されている人口を取りまとめた資料である。第6表は年齢各歳、男女別の日本人人口をCSVで公開しており、3-5歳、6-11歳、12-14歳、15-17歳を推測なしに集計できるため採用した。

## 採用しなかった候補

| 候補 | 利点 | 採用しなかった理由 |
| --- | --- | --- |
| 東京都 第1表 区市町村、世帯数、男女別人口 | 同じ東京都公式資料で、外国人人口を含む総人口を確認できる | 年齢各歳の内訳がないため、校種相当年齢人口を直接算出できない |
| 東京都 第7表 区市町村、年齢5歳階級、国籍、男女別人口 | 同じ基準日の日本人・外国人人口を含む年齢階級データ | 5歳階級のため、3-5歳、6-11歳、12-14歳、15-17歳を境界通りに算出できない |
| e-Stat 人口推計系統 | 国の統計ポータルで比較対象として有用 | 推計値または5歳階級が中心で、東京都公式の各歳CSVより今回の要件に合わない |
| 東京都統計年鑑 | 東京都公式で長期比較に有用 | 年鑑形式で速報性・粒度が今回のカード表示要件より弱い |

## 算出方法

第6表CSVから、地域コード13000、地域「総数」の行だけを使用した。総人口は年齢「総数」の総数(人)を採用し、校種相当年齢人口は次の年齢各歳を合算した。

- 幼稚園相当年齢: 3-5歳
- 小学校相当年齢: 6-11歳
- 中学校相当年齢: 12-14歳
- 高等学校相当年齢: 15-17歳
- 校種相当年齢人口: 3-17歳

割合は、各人口を総人口で割った値を内部データでは小数6桁まで保持し、画面では小数1桁で表示した。

## 算出結果

| 項目 | 人口 | 総人口比 |
| --- | ---: | ---: |
| 総人口 | 13,293,851人 | 100.0% |
| 幼稚園相当年齢 3-5歳 | 266,188人 | 2.0% |
| 小学校相当年齢 6-11歳 | 610,624人 | 4.6% |
| 中学校相当年齢 12-14歳 | 313,542人 | 2.4% |
| 高等学校相当年齢 15-17歳 | 316,843人 | 2.4% |
| 校種相当年齢人口 3-17歳 | 1,507,197人 | 11.3% |

## 注意点

今回の総人口と年齢人口は日本人人口で統一している。外国人人口を含む総人口を分母にすると、同じCSVから年齢各歳の分子を得られず、定義が混在するため採用しなかった。

カード上の「校種相当年齢人口」は、各校種に相当する年齢層の人口であり、実際の在学者数ではない。就学猶予、留年、早生まれの学年境界、区域外通学、国私立校への進学、未就園、通信制などは反映していない。

## 実装範囲

試験実装のため、対象は東京都のみとした。既存の学校データJSONには人口情報を混在させず、`data/school-database/prefecture-population-pilot.json` に分離した。
