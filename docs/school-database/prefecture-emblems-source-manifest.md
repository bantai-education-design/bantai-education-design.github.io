# 都道府県章・シンボルマーク 一次資料調査

作成日: 2026-08-01
対象: 全国学校データベース47都道府県カードに表示する「都道府県章」または「公式シンボルマーク」

## 調査方針・採用基準

- 各都道府県庁の公式サイト（`pref.xxx.lg.jp`等の公式ドメイン）だけを情報源とした。
- Wikipedia、Wikimedia Commons、まとめサイト、民間サイト、観光連盟等の外郭団体サイトからの画像取得は行っていない。
- マークの手描き再現・AI生成は行っていない。
- 対象は都道府県章または公式シンボルマーク単体。県旗全体の画像は対象外。
- 優先順位: 1) 公式サイト配布のSVG　2) 公式サイト配布のPNG　3) 公式サイト掲載画像を利用規程の範囲内で使用　4) 公式PDF内の章を抽出（最後の手段）。
- **採用基準**: 公式サイト上に「事前の承認申請・審査・届出を一切必要とせず、誰でも確実に無料で利用できる」と明記されている場合のみ採用する。
  - 「事前の承認申請（審査あり・不承認もありうる）」が必要なものは不採用。
  - 「事前の届出（審査なしだが提出自体が必須）」が必要なものも、今回は不採用とした（ユーザーへの確認質問を提示したが未回答のため、当初の厳格な基準を維持）。
  - 利用条件が公式サイト上で確認できない場合、または発信元が都道府県庁公式ドメイン以外（観光連盟・外郭団体サイト等）の場合も不採用とした。
  - 期間限定の記念ロゴ・キャンペーンロゴ・特定施策専用ロゴ（都道府県を恒常的に代表するシンボルでないもの）も対象外とした。

## 富山県マークの画像処理について

富山県観光課が配布する公式ファイルは、「シンボルマーク＋キャッチフレーズ文字」が一体化した組合せ（シグネチャー）画像のみで、マーク単体のダウンロードファイルは提供されていない（`https://www.pref.toyama.jp/810111/miryokukankou/kankoutokusan/kankou/kj00005907.html` に掲載の14ファイルはすべてカラー版/カラー枠あり版/白黒版×文字位置4パターンの組合せ画像で、マーク単体版はなし）。

一方、公式デザインマニュアル（`https://www.pref.toyama.jp/documents/4677/01285285.pdf`）には「保護エリア」の説明図として、マーク単体（キャッチフレーズなし）の図が掲載されており、マーク単体での認識・使用が公式に想定されていることを確認した。このため、公式配布のシグネチャー画像から、キャッチフレーズ文字部分を含まないマーク図形のみを機械的に切り出した（色・形状・比率は一切変更していない）。

処理内容:

1. 公式配布JPEG（`01285287.jpeg`、515×295px）から、キャッチフレーズ文字列とマーク図形の間の空白部分を基準に、マーク図形のみを座標指定でクロップ（`x=223〜481, y=30〜253`、8pxの余白を含む）。
2. クロップ後の色を実測し、公式指定色と一致することを確認:
   - 上部（山）: 実測RGB(65,180,177) — 指定色 Toyama BLUE（PANTONE 3115C）と整合
   - 下部（湾）: 実測RGB(37,51,148) — 指定色 Toyama DEEP BLUE（PANTONE 286C）と整合
   - JPEG圧縮による誤差はあるが、色相・彩度の意図的な変更は一切行っていない。
3. 白背景から透過背景（RGBA）へ変換（形状の変形・拡大縮小による比率変更は行っていない）。
4. `assets/images/prefecture-emblems/16-toyama.png` として保存（258×223px、22,254バイト）。

デザインマニュアルの禁止事項（指定色の変更・重ね表示・変形・キャッチフレーズ書体変更・強烈な背景への表示）のいずれにも該当しない。
