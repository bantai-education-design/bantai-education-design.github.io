# 新潟県学校データ 原本管理表

更新日: 2026-07-25
原本保存先: `data-source/niigata/2025/`（Git管理外、ローカル作業用）

## 収録対象

福島県版・宮城県版と同じ方針で、次を収録する。

- 公立・私立幼稚園
- 公立・私立小学校
- 公立・私立中学校
- 公立義務教育学校
- 県立・私立高等学校
- 県立・県立中学校・中等教育学校
- 県立・市立特別支援学校

専修学校・各種学校・認定こども園・大学は初版対象外（既存都道府県版と同じ除外方針）。

新潟県は政令指定都市（新潟市）を含むため、県教育委員会が公開する県内一覧
（後述）は新潟市立の小学校・中学校・幼稚園等を含まない。新潟市が別途公開する
「学校便覧」で新潟市立分を補い、県内全域を網羅した。

## 新潟市立学校便覧（新潟市教育委員会、令和8年度）

出典ページ: https://www.city.niigata.lg.jp/kosodate/gakko/gakko_keikaku/indexbinran.html

| ファイル | 内容 |
| :--- | :--- |
| niigatacity_elementary.xlsx | 新潟市立小学校一覧（106校） |
| niigatacity_middle.xlsx | 新潟市立中学校一覧（57校） |
| niigatacity_kindergarten.xlsx | 新潟市立幼稚園一覧（5園。新潟市立幼稚園は
  近年の統廃合により現在5園のみ） |
| niigatacity_high.xlsx | 新潟市立高等学校一覧（万代高等学校・明鏡高等学校の
  全日制/定時制2校） |
| niigatacity_secondary.xlsx | 新潟市立中等教育学校一覧（高志中等教育学校1校） |
| niigatacity_special_needs.xlsx | 新潟市立特別支援学校一覧（東特別支援学校・
  西特別支援学校の2校） |

小学校・中学校・幼稚園は1校1行だが、郵便番号・所在地の列が「950-」「3126」の
ように隣接2列（幼稚園は隣接2"行"）に分割されているため、変換スクリプト側で
連結している。高等学校・中等教育学校・特別支援学校は学級数等を学部・課程別の
行に分けて記載する結合セル形式で、該当校が極めて少数（合計5校）のため、原本を
目視で確認したうえで `convert_niigata_workbooks.py` 内に直接値として保持した。

**原本の誤記1件を補正**: 「荻川小学校」の所在地が原本で「新潟市秋葉車場」と
なっており、同じ区内の他11校がすべて「新潟市秋葉区◯◯」と表記されているのに
対し「区」の文字が欠落している。他行との比較から明白な誤記と判断し、
「新潟市秋葉区車場」に補正した。

## 県立高等学校・中等教育学校・県立中学校（所在地・電話番号）
（新潟県教育庁 高等学校教育課、令和8年度）

出典ページ: https://www.pref.niigata.lg.jp/sec/kotogakko/
PDF: 「新潟県立高等学校・中等教育学校 学校概覧（所在地、電話・FAX番号）」

このPDFは表がテキスト抽出時に列単位（学校名＋所在地の列がまとまった後に
電話番号の列がまとまって続く）でしか取り出せないため、`convert_niigata_workbooks.py`
内でテキストを解析し、学校名・所在地の並び順と電話番号の並び順が一致することを
前提にカーソル方式で対応付けている。ページ跨ぎで複数の課程（全日制・定時制・
通信制）や学校種（中等教育学校・県立中学校）の見出しをまたいでから電話番号の
まとまりが複数回出現する箇所があり、見出しが変わっても電話番号を割り当てる前の
学校名リストを保持し続けるよう実装した。

全日制・定時制・通信制で同一校（同一名・同一住所）が複数回掲載されている場合は
1校へ統合し、課程を `course` に合算している（「番地」の有無だけが異なる表記
ゆれは統合キー算出時のみ吸収し、格納する住所自体は変更していない）。分校・
キャンパス（佐渡高等学校両津キャンパス、佐渡高等学校相川分校など）は所在地が
本校と異なるため独立レコードとして保持した。

なお、県立中学校・中等教育学校については pref_middle_secondary.xlsx の方が
構造化されており重複するため、このPDFからは高等学校のみを採用している。

## 私立中学校・高等学校、私立幼稚園（新潟県 大学・私学振興課）

出典ページ: https://www.pref.niigata.lg.jp/sec/daigaku/1204131691988.html
（ページ更新日: 2026年6月3日）

| ファイル | 内容 |
| :--- | :--- |
| 私立中学・高等学校の一覧.pdf | 私立高等学校20校・私立中学校3校 |
| 私立幼稚園の一覧.pdf | 私立幼稚園36園 |

いずれもテキスト抽出結果が列単位（学校名列→課程列→学科列→郵便番号/住所/
電話/HP列、または住所→電話→園名のように行内でも順序が入れ替わる）になり、
機械的な行パースでは信頼できる対応付けができなかったため、原本の記載順序を
目視で1件ずつ照合し、`convert_niigata_workbooks.py` 内に確定値として直接
保持した。

**私立幼稚園の郵便番号を補完**: 私立幼稚園一覧PDFには郵便番号の記載がない
（学校名・住所・電話番号・HPのみ）。学校名・住所・電話番号を原本から転記した
うえで、郵便番号のみ日本郵便公式の郵便番号データ（read-me: 住所の郵便番号、
UTF-8形式、https://www.post.japanpost.jp/zipcode/download.html）を新潟県内の
町域名でつき合わせ、36園すべてで町域名が一意に一致した郵便番号を採用した。
学校名・住所・電話番号を推測で補うことはしていない。

## 市町村表示順

新潟県教育委員会公開資料の地域区分（新潟市の各区 → 上越教育事務所管内 →
中越教育事務所管内 → 下越教育事務所管内）に準拠した。郡部の町村（阿賀町・
津南町・聖籠町・出雲崎町・刈羽村・弥彦村・湯沢町・田上町・粟島浦村・関川村）は
住所表記が「郡名+町村名」になる場合があるため、郡名付き表記からも同じ市町村名へ
引き当てられるようにしている。

## 品質基準（既存都道府県版を継承）

- 学校名、住所、電話番号は推測で補わない（私立幼稚園の郵便番号のみ、公的機関の
  別データで補完したことを明記）。
- 電話番号は市外局番＋市内局番＋番号の形式に正規化する。
- 基本検証（`validate_school_data.py`）は0件エラーで合格。831件、7校種、
  市町村37区分すべてに学校が存在することを確認済み。
