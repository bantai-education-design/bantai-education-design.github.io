# 岩手県学校データ 原本管理表

更新日: 2026-07-28
作業ブランチ: `feature/school-database-iwate`
原本保存先: `data-source/iwate/`（Git管理外、ローカル作業用）

## 収録対象

既存都道府県版と同じ方針で、次を収録する。

- 国立・公立（県立・市町村立）・私立幼稚園
- 私立幼保連携型認定こども園（公立は九戸村立1園のみ確認）
- 国立・公立（市町村立）・私立小学校
- 国立・公立（市町村立）・私立中学校
- 公立（県立・市立）・私立高等学校
- 国立・公立（県立）特別支援学校

義務教育学校・中等教育学校は岩手県内に該当校が確認できなかったため0件。
専修学校・各種学校・大学・短期大学は対象外（既存都道府県版と同じ除外方針）。

## 原本形式: 公立は単一PDF（統計編＋学校一覧編）、私立は罫線PDF

岩手県教育委員会は、国・県立・市町村立の幼稚園・小学校・中学校・義務教育学校・
高等学校・特別支援学校をまとめた単一PDF「学校一覧」を公開している。

出典: https://www.pref.iwate.jp/_res/projects/default_project/_page_/001/006/311/r7ichiran3.pdf
（令和7年度「学校一覧」、41ページ、基準日 令和7年5月1日）

- p.1〜17: 「Ⅰ統計編」（学校数集計表のみ、未使用）
- p.20: 幼稚園（市町村立）一覧
- p.21〜33: 小・中・義務教育学校一覧
- p.34〜38: 高等学校（県立・市立）一覧
- p.39〜40: 特別支援学校（県立）一覧

学校一覧編は罫線のない統計表形式のPDFで、pdfplumberの`extract_tables()`では
1校ごとの行が正しく分離できず、多数の学校が1つの巨大なセルに結合されて
しまう。そのため`extract_text()`で1行ずつテキスト化し、正規表現で郵便番号・
住所・電話番号の並びを起点に学校名を抽出する方式（`convert_iwate_sources.py`）
を採用した。

なお、幼稚園・小中学校の欄では学校名が「太 田」のように1文字ずつ空白区切りで
出力されるのに対し、同じPDF内でも高等学校の欄は「盛岡第一」のように空白なしで
出力される。1つの正規表現では両方に対応できないため、セクションごとに異なる
名前抽出パターンを用いている。

## 私立学校名簿PDF（1ファイル35ページ、基準日 令和7年5月1日）

出典: https://www.pref.iwate.jp/_res/projects/default_project/_page_/001/006/748/r7itiran.pdf

| ページ | 内容 |
| :--- | :--- |
| 4〜7ページ目 | 幼稚園・幼保連携型認定こども園（休園中の園は除外） |
| 8ページ目 | 中学校 |
| 9〜11ページ目 | 高等学校 |

こちらは罫線表のためpdfplumberの`extract_tables()`で正しく1校1行として
抽出できる。郡市名（1列目）はrowspanで結合されているため、値がある行で
`current_muni`を更新し、値が空の行は直前の市町村を引き継ぐ方式で復元した。

## 特別支援学校（県立）: 手動転記

原本PDF（学校一覧）p.39〜40は幼稚部・小学部・中学部・高等部が学校ごとに
複数行へ分かれる複雑な表形式で、機械的な抽出では列がずれるため、目視で
`data-source/iwate/tokushi_transcribed.tsv`へ書き起こした（15校＋1分教室）。

## 国立学校: 岩手大学教育学部附属校（大学公式サイト記載）

岩手大学教育学部附属幼稚園・小学校・中学校・特別支援学校の4校を、大学公式
サイトの記載住所・電話番号から直接収録した（`NATIONAL_SCHOOLS`定数）。

## 学校名の正式名称化について

北海道版・山梨県版と同様、原本の名簿は「太田」「六原」のように学校名の
核となる部分のみが記載され、設置者（市町村立）や校種（幼稚園等）が省略
されている。`build_official_name()`で `{設置者}立{校名}{校種}` の形式に
組み立てて正式名称化している。

変換時に2件の既知の抽出崩れを個別修正した。

- 幼稚園一覧（p.20）は1行内に「市町村名列」と「園名列」が並ぶ表形式だが、
  市町村が変わる行（先頭行）ではpdfplumberのテキスト抽出時に両方の列の
  文字列が連結されてしまい、「盛岡市太田」のように市町村名が二重に混入する。
  住所から市町村名を再判定したうえで、学校名側から重複する市町村名を
  除去する処理を追加した（対象7件: 盛岡市太田・北上市黒沢尻・花巻市花巻・
  奥州市小山東・釜石市鵜住居・一関市舞川・平泉町立幼稚園）。
- 九戸村の公立幼保連携型認定こども園「ひめほたるこども園」は、原本PDFで
  園名が前後のページ行（「幼稚園ひめほた」/「る こ ど も 園」）に分裂して
  出力されていたため、住所をキーとした個別補正（`KNOWN_NAME_CORRECTIONS`）
  で正しい名称・校種に修正した。

## 郡名の混入について

私立学校名簿PDFの郡市名列および特別支援学校の手動転記データでは、住所の
先頭に「上閉伊郡」「紫波郡」のような郡名が付与された市町村（大槌町・山田町・
紫波町・矢巾町）が、市町村名ではなく郡名としてそのまま抽出されてしまう
問題があった。住所文字列から郡名を除いた実際の市町村名を再抽出する処理
（`municipality_from_address` / `strip_gun_prefix`）を追加し、全33市町村
（14市15町4村）が正しく収録されていることを確認済み。

## 品質基準（既存都道府県版を継承）

- 学校名、住所、郵便番号、電話番号は推測で補わない。
- 電話番号は市外局番＋市内局番＋番号の形式に正規化する。
- 休園中と原本に明記された私立幼稚園は公開対象から除外する。
- 公式HP（website）は、今回の初期変換では確実に判定できるものがないため全件空欄。
- 基本検証（`validate_school_data.py --prefecture 岩手県`）は総件数502件で合格。

## 既知の残課題

- `name_kana`（学校名のかな読み、小・中学校のみ収録）のうち3件
  （滝沢市立月小学校、盛岡市立緑小学校、紫波町立西小学校）で、元PDFの
  1文字校名に対する正規表現抽出が不完全なため、かな読みが1文字のみと
  なっている。校名・住所・電話番号など主要項目には影響しない、検索補助
  フィールドのみの軽微な既知事項。
