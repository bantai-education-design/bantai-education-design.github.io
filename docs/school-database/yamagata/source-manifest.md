## 正式名称化の方針

山梨県版（PR #68/#69）での略称問題、茨城・栃木県版の `build_official_name` による設置者＋校種構築ルールを継承する。  
一次データとして**文部科学省「学校コード一覧（全国公立・国立・私立学校等）」（2026年5月29日版）**を採用した。  
このデータでは各校の設置区分・自治体名・正式名称が国の公式記録として登録されており、略称問題の根本を解消している。

変換スクリプト（`convert_yamagata_sources.py`）内の `build_official_name()` では以下の修正が施されている：

| ケース | 対応 |
| :--- | :--- |
| MEXT名称に既に「○立」が含まれる場合（例:「山形市立商業高等学校」「山形県立致道館中学校」） | そのまま返す（「山形県立」を二重付与しない） |
| 分校名が「〜山形校」「〜金山校」等 `校$` で終わる場合 | 校種サフィックスを付けない（「特別支援学校」重複防止） |
| 国立・私立 | MEXT 登録名称をそのまま採用 |
| 公立県立（高校・中等教育・特別支援） | `山形県立` + 校名 |
| 公立市町村立（幼稚園・小・中・義務） | 自治体名 + `立` + 校名 |
