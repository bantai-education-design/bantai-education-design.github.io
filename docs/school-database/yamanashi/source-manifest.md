# 山梨県学校データ 原本管理表

更新日: 2026-07-26
作業ブランチ: `feature/school-database-yamanashi-phase1`
原本保存先: `data-source/yamanashi/2025/`（Git管理外、ローカル作業用）

## 千葉県版・神奈川県版との違い

山梨県は学校名簿がExcelではなくPDF（表形式の住所録）で公開されている。
Excelのように見出し行から列を検出する方式ではなく、pdfplumberでPDF内の表を
直接抽出する方式（`tools/school-database/convert_yamanashi_sources.py`）を
新規に採用した。

## 収録対象・原本

すべて山梨県教育委員会「山梨県内の学校・学級・児童生徒数等」（令和7年度、
基準日 令和7年5月1日）の住所録、および山梨県「山梨県私立学校名簿」
（令和7年4月1日現在）。

出典ページ: https://www.pref.yamanashi.jp/kyouiku/27458338247.html

| ファイル | 内容 | 校種 |
| :--- | :--- | :--- |
| r7_13_shogakko_address.pdf | 住所録【小学校】（国・公・私立） | 小学校 |
| r7_14_chugakko_address.pdf | 住所録【中学校】（国・公・私立） | 中学校 |
| r7_15_koukou_tokushi_address.pdf | 住所録【高校・通信・特別支援】（公・私立混在） | 高等学校・特別支援学校 |
| r7_16_youchien_address.pdf | 住所録【幼稚園】（私立中心・国立1園） | 幼稚園 |
| shiritsu_gakkou_meibo.pdf | 私立学校名簿（令和7年4月1日現在） | 設置者・課程の確認用 |

義務教育学校・中等教育学校は、上記いずれの資料にも該当校が見当たらなかったため
未収録（山梨県内に現時点で該当校が無いためと判断）。

## 設置区分（公立/私立/国立）の判定方法

住所録PDFには設置区分の列が無いため、次の方法で判定した。

- 「山梨大学附属」を含む学校名 → 国立
- 私立学校名簿PDFに掲載されている学校名（既知リストとして
  `convert_yamanashi_sources.py` にハードコード）に一致 → 私立
- それ以外 → 公立

## 高等学校の課程（全日制・定時制・通信制）

- 住所録PDFの学校名に「（定時制）」の注記があるものは、本校（全日制）と
  同一学校として統合し、`course` に "定時制" を追加する。
- 通信制は住所録内に別建ての一覧があり、名称の一致で判定して `course` に
  "通信制" を追加する。
- 帝京第三高等学校の通信制課程（令和7年1月21日認可）は、私立学校名簿PDFには
  掲載されているが住所録PDFの通信制一覧には反映されていなかったため、
  私立学校名簿を根拠に手動で補正した（変換スクリプト内に理由をコメントで明記）。
- 「（専攻科：○○科）」の注記がある行は、本校と所在地が同一の専攻科であり
  独立した学校ではないため、別レコード化していない。

## 除外・補完した行

- 「分校」「分教室」を含む行（例: 山城小分校、桜木分校、城南中分校、
  ふじかわ分校、旭分校）は、本校と所在地・電話番号が重複するため初版では
  収録対象外とした。
- 所在地欄が空欄の幼稚園（「（H30.3.31閉園）」「（R2.3.31閉園）」等の注記のみ、
  または単に空欄）は、廃園・休園とみなして除外した。
- 幼稚園住所録PDFの「立正」の行は、表抽出時にページフッター
  （「幼稚園1/2」）がセルに混入し所在地を正しく取得できなかったため、
  今回は収録を見送った（推測での補完はしていない）。
- 私立学校名簿PDFにのみ掲載され、住所録PDFには掲載がなかった「素和美小学校」
  「素和美中学校」（学校法人素和美国際教育学院、南都留郡富士河口湖町小立5703）は、
  私立学校名簿PDF記載の住所・電話番号をそのまま用いて手動で追加した
  （`convert_yamanashi_sources.py` の `MANUAL_ADDITIONS` を参照）。

## 品質基準（千葉県版・神奈川県版を継承）

- 学校名、住所、郵便番号、電話番号は推測で補わない。
- 公式HP（website）は、今回の初期変換では確実に判定できるものがないため全件空欄。
