# 福島県学校データ 原本管理表

更新日: 2026-07-25
作業ブランチ: `feature/school-database-fukushima-phase1`
原本保存先: `data-source/fukushima/2025/`（Git管理外、ローカル作業用）

## 収録対象

千葉県版・神奈川県版と同じ方針で、次を収録する。

- 私立幼稚園（福島県には公立幼稚園の公式名簿が別途確認できず、市町村立学校一覧にも
  幼稚園は含まれていなかったため、今回のスコープでは私立のみ収録）
- 国立・公立・私立小学校
- 国立・公立・私立中学校
- 公立義務教育学校
- 県立・私立高等学校
- 県立・市立・国立特別支援学校

専修学校・各種学校・大学は対象外（既存都道府県版と同じ除外方針）。福島県には
中等教育学校（併設型ではない単独の中高一貫校）の設置がないため、この校種は
今回収録していない（安積中学校・会津学鳳中学校・ふたば未来学園中学校は併設型の
「県立中学校」であり、学校種は「中学校」として収録した）。

## 既存都道府県版との最大の違い: 原本形式がExcelではなくPDF/CSV

千葉県版・埼玉県版・神奈川県版はいずれも原本がExcelブックだったが、福島県教育委員会の
公開資料は市町村立学校一覧・私立学校名簿がPDF、県立学校一覧のみCSV（オープンデータ）
という構成だった。そのため `convert_fukushima_workbooks.py` は openpyxl ではなく
pdfplumber（表抽出）とCSV直接パースを組み合わせて実装している。

## 県立学校（福島県教育委員会 特別支援教育課ほか、基準日 令和8年4月1日）

出典ページ: https://www.pref.fukushima.lg.jp/site/edu/kenritu.html
（CSVは同ページからリンクされている「オープンデータ（CSV形式）公開ページ」
https://www.pref.fukushima.lg.jp/sec/70057a/koukoukyoiku02.html 経由で取得）

ファイル: `r8_kenritsu_gakkou_ichiran.csv`（Shift_JIS/CP932エンコード）

1ファイルに以下4カテゴリが見出し行で区切られて収録されている。

| カテゴリ見出し | 内容 |
| :--- | :--- |
| （１）県立高等学校・特別支援学校 | 高等学校74校＋特別支援学校18校（校名に「支援」を含む行で判定）＋無番号の校舎4行（小野校舎など） |
| （２）県立中学校 | 併設型中高一貫校の中学校部分3校（安積・会津学鳳・ふたば未来学園） |
| （３）県立学校の分校 | 高等学校の分校1校（浪江高等学校津島校、休校中のため除外）＋特別支援学校の分校8校 |
| （４）県立学校の校舎及び協力校 | 特別支援学校の協力校2校（たむら支援・あだち支援） |

特別支援学校の内訳（県立18校8分校、市立1校、国立1校＝合計28校）は、福島県特別支援
学校一覧ページ（https://www.pref.fukushima.lg.jp/site/edu/tokubetsushien03.html ）
記載の内訳と一致することを確認済み。

「浪江高等学校 津島校」は局番欄に「休　校　中」（全角スペース入り）と記載されて
おり、単純な部分一致では検出できなかったため、休校判定ロジックは全角スペース等の
空白を除去してからキーワード照合するよう実装した。

## 国立特別支援学校（例外的に手動転記）

出典ページ: https://www.pref.fukushima.lg.jp/site/edu/tokubetsushien03.html
（PDF: 福島県特別支援学校一覧、令和8年4月1日現在）

福島大学附属特別支援学校（国立、1校のみ）は上記PDFが罫線のない自由記述形式で、
学校ごとにセルの折り返し行数が不規則なため、表として自動抽出すると誤読の
リスクが高いと判断した。該当PDFを目視で読み取り、`convert_fukushima_workbooks.py`
内の `national_special_needs_school()` 関数に直接値を記載する方式にした
（1校のみの例外的な対応）。

## 私立学校（福島県 私学・法人課、基準日 令和7年5月1日）

出典ページ: https://www.pref.fukushima.lg.jp/sec/01135b/shigaku13.html

県立・市町村立（令和8年4月1日）より1年古い基準日のPDFしか公開されていなかった。

| ファイル | 内容 |
| :--- | :--- |
| r7_shiritsu_koukou.pdf | 高等学校（5列表: 番号／学校名・設置者・法人番号・電話／校長・認可日／定員／所在地・電話・FAX） |
| r7_shiritsu_chu_shou.pdf | 中学校・小学校混在（同一表構造、学校名の末尾「中学校」「小学校」で判定） |
| r7_shiritsu_youchien.pdf | 幼稚園（7列表: 番号／区分／園名・設置者・法人番号／園長／認可日／定員／所在地・電話） |

専修学校（r7_shiritsu_senshuu.pdf）・各種学校（r7_shiritsu_kakushu.pdf）は
取得はしたがスコープ外のため変換対象に含めていない。

私立高等学校名簿に掲載されている「福島南高等学校」（学校法人福島南学園、
昭和43年認可）は、1968年開校・1969年に休校して以降、事実上の廃校状態のまま
帳簿上のみ存続している学校で、原本PDFにも所在地・電話番号の記載が一切ない。
休園・休校中の学校を除外する既存方針にならい、収録対象から除外した。

「学校法人石川高等学校」（石川郡石川町、通称「学法石川」）は、運営法人
「学校法人石川義塾」と学校の正式名称が異なる（同じ石川町内の県立石川高等学校と
区別するための通称に対し、学校の正式名称自体に「学校法人」を含む）珍しいケース。
原本PDFの記載どおりに収録しており、誤変換ではない。

## 市町村表示順

福島県公式の広域振興局区分（県北・県中・県南・会津・南会津・相双・いわき）に
準拠した。南相馬市の行政区（原町区・鹿島区・小高区）は政令指定都市の区ではない
（合併に伴う地域自治区）ため、区単位では分割せず「南相馬市」に統合している。

## 品質基準（既存都道府県版を継承）

- 学校名、住所、郵便番号、電話番号は推測で補わない。
- 電話番号は市外局番＋市内局番＋番号の形式に正規化する。「024-557-0135・1614」の
  ように内線・複数番号が「・」等で併記されている場合は代表番号（先頭の番号）のみ
  採用する。
- 休園・休校中と原本に明記された学校は公開対象から除外する。
- 公式HP（website）は、今回の初期変換では確実に判定できるものがないため全件空欄。
- 基本検証（`validate_school_data.py`）は0件エラー・0件警告で合格。
