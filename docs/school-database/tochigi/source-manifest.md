## 最重要: 学校名の正式名称化について

山梨県版（PR #68/#69）において、原本データに含まれていた学校名の略称（例:「梨大附属」「伊勢」「羽黒」）をそのまま収録してしまい、宛名用データベースとして不都合が生じた経緯がある。また、茨城県版でも原本の「学校名」列が略称（例:「三の丸」「日立第一」）で記載されていたため、変換時に設置者＋略称＋校種サフィックスを組み合わせて正式名称を構築する対応を行った。

栃木県版においては、都道府県が公開する一部の概況速報・簡略表などでの略称記載リスクを根絶し、初版より100%正式な法的学校名称を網羅するため、一次情報源として**文部科学省の公式「学校コード一覧（全国公立・国立・私立学校等）」**をベースデータとして採用した。この全国データでは、各校の設置区分および自治体・大学名を含む正式名称が初めから付与されている。

さらに、データ変換スクリプト（`convert_tochigi_sources.py`）においては茨城県版の設計を踏襲し、`build_official_name()` により全ての学校名が次の形式を満たすよう検証および補正処理を行っている。

```
設置者（市町村名／「栃木県」／「国立大学法人」等） + 学校略称・固有名称 + 校種サフィックス
```

| 学校の分類・区分 | 収録される正式名称の実例 |
| :--- | :--- |
| 国立大学法人附属校（幼稚園〜特支） | 宇都宮大学共同教育学部附属小学校、宇都宮大学共同教育学部附属中学校等 |
| 公立（市町村立）小学校・中学校 | 宇都宮市立中央小学校、足利市立けやき小学校、那珂川町立馬頭中学校 |
| 公立（県立）高等学校・中等教育学校 | 栃木県立宇都宮高等学校、栃木県立佐野桜和高等学校 |
| 公立・私立特別支援学校 | 栃木県立盲学校、栃木県立岡本特別支援学校 |
| 私立小学校・中学校・中等教育・高等学校 | 作新学院小学部、作新学院中等部、佐野日本大学中等教育学校、文星芸術大学附属高等学校 |

- 出典ページ: https://www.mext.go.jp/b_menu/toukei/mext_01087.html
- 保存ファイル: `sc_221222-mxt-mxt_chousa01-1000011635_1.xlsx` および `tochigi_mext_schools.csv`
- スコープ: 栃木県内の現職中の全校種を対象。休校・閉校（属性情報廃止年月日が記載されている学校）は正確に除外し、稼働校のみを抽出。

- 私立小・中・高校名簿: `private_schools.pdf`
- 上記県公開資料との対照検証を行い、表記および校種構成の整合性を確認済み。
