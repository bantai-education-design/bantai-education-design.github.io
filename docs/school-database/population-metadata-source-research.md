# 全国学校データベース 人口メタデータ資料調査

作成日: 2026-07-31
対象: 全国47都道府県カードへ表示する人口・校種相当年齢人口メタデータ

## 前提

- ダミー値、推計按分、5歳階級の均等分割は採用しない。
- `data/school-database/prefecture-card-metadata.json` へ人口値は追加しない。
- 東京都パイロットは、東京都公式「住民基本台帳による東京都の世帯と人口 令和8年1月 第6表」の日本国籍住民・年齢各歳データを使用している。
- 全国展開では、東京都だけ2026年住民基本台帳、他県だけ2020年国勢調査という混在は避ける。

## 全国共通資料の確認

### 総務省統計局 人口推計

- 公式ページ: https://www.stat.go.jp/data/jinsui/2.html
- 最新結果ページ: https://www.stat.go.jp/data/jinsui/new.html
- e-Stat検索結果では「人口推計は、毎月1日現在の男女別、年齢階級別人口を推計」「毎年10月1日現在の全国各歳別結果及び都道府県別結果も推計」と説明されている。
- ただし、公開表として確認できる都道府県系列は、都道府県別人口割合、増加率、年齢階級等が中心。
- 都道府県別に3～5歳、6～11歳、12～14歳、15～17歳を正確合算できる各歳表は未確認。
- 推計であること、年齢不詳や補間補正を含む系列があることも、学校DBカード上の説明を難しくする。

判断: 現時点では不採用。都道府県別各歳表のCSV/APIが確認できた場合のみ再検討。

### e-Stat 住民基本台帳に基づく人口、人口動態及び世帯数調査

- e-Stat検索: https://www.e-stat.go.jp/stat-search/files?layout=dataset&page=1&query=%E4%BD%8F%E6%B0%91%E5%9F%BA%E6%9C%AC%E5%8F%B0%E5%B8%B3%E3%80%80%E5%B9%B4%E9%BD%A2%E9%9A%8E%E7%B4%9A%E5%88%A5%E4%BA%BA%E5%8F%A3
- 確認できた表:
  - 「都道府県別年齢階級別人口（日本人住民）」
  - 「都道府県別年齢階級別人口（外国人住民）」
  - 「都道府県別年齢階級別人口（総計）」
  - 「市区町村別年齢階級別人口（総計）」
- 表名が「年齢階級別」であり、例示される列も0～4歳、5～9歳等の階級。
- 外国人住民では秘匿・合計不一致に関する注記がある。

判断: 東京都パイロットに近い「住民基本台帳・日本人住民・1月1日」の全国版として最も望ましいが、現時点で確認できた全国表は年齢階級別のため不十分。各歳版がe-Stat APIまたは総務省自治行政局側に分割掲載されていないか継続確認が必要。

### 令和2年国勢調査 表2-1

- e-Statファイル: https://www.e-stat.go.jp/stat-search/files?cycle=0&tclass=000001125102
- DB表示候補: https://www.e-stat.go.jp/dbview?sid=0003445133
- 表題: 「男女，年齢（各歳），国籍総数か日本人別人口，平均年齢及び年齢中位数－全国，都道府県，21大都市，特別区，人口50万以上の市」
- 調査年月: 2020年10月
- 公開更新日: 2021-11-30

確認できたこと:
- 47都道府県を同一定義で集計できる可能性が高い。
- 年齢各歳、国籍総数、日本人別を持つ。
- 3～17歳、3～5歳、6～11歳、12～14歳、15～17歳を単純合算できる可能性が高い。

未確認・要検証:
- 年齢不詳・国籍不詳の扱い。
- 表2-1の「国籍総数か日本人別」が、外国人を含む総数と日本人を明確に分けるか。
- 東京都2026年住民基本台帳値との差分が利用者に混乱を与えないか。

判断: 予備案として有力。ただし採用する場合は全47県を2020年国勢調査値に統一し、東京都2026年値はカードから外すか別系列として扱う。

## 案A・B・C比較

### 案A: 最新の全国共通各歳資料を採用

- 正確性: 高い。各歳なら校種相当年齢を正確合算できる。
- 鮮度: 住民基本台帳の各年1月1日表が見つかれば高い。
- 比較可能性: 高い。
- 更新作業量: 低～中。全国表1本なら自動化しやすい。
- 再現性: 高い。
- 利用者の分かりやすさ: 高い。
- 毎年更新: 可能。

現状: 条件を満たす全国共通・最新・各歳・国籍区分付き資料は未確認。

### 案B: 各都道府県の最新公式各歳資料を個別収集

- 正確性: 県により異なる。住基実数、常住人口推計、国勢調査基礎推計が混在する。
- 鮮度: 高い県もある。
- 比較可能性: 低い。
- 更新作業量: 高い。
- 再現性: 県ごとのファイル形式差が大きい。
- 利用者の分かりやすさ: 低～中。基準日・定義差をカードで説明する必要がある。
- 毎年更新: 運用負荷が高い。

現状: 埼玉県は有力だが、茨城・栃木・群馬は推計色が強く東京都定義と合わない。

### 案C: 令和2年国勢調査で47都道府県を同一基準日に統一

- 正確性: 高い。ただし国勢調査の不詳扱いを要確認。
- 鮮度: 低い。2020年10月値。
- 比較可能性: 高い。
- 更新作業量: 中。表2-1から47県を一括抽出できる可能性あり。
- 再現性: 高い。
- 利用者の分かりやすさ: 中。「2020年国勢調査」と明示すれば誤解を抑えられる。
- 毎年更新: 不可。5年周期。

現状: 全国統一定義を優先する場合の予備案。令和7年国勢調査の人口等基本集計公開後に同等表へ更新するのが自然。

## 推奨案

現時点の推奨は次の順。

1. 案Aを継続探索する。特に e-Stat API と総務省自治行政局の住民基本台帳関連統計で「市区町村別または都道府県別・年齢各歳・日本人住民/総計」を探す。
2. 案Aが存在しないと確認できた場合、令和7年国勢調査の人口等基本集計公開を待つ。
3. すぐ全国表示を出す必要がある場合のみ、案Cとして令和2年国勢調査表2-1へ全47県を統一する。
4. 案Bは、県ごとの定義差が大きく、全国カードで比較値として並べるには注意が必要なため優先しない。

## 東京都2026年データの扱い

- 案Aで全国共通の2026年または最新住基各歳データが見つかる場合: 東京都パイロットを全国共通データへ置き換える。
- 案Cを採用する場合: 東京都2026年値はカード表示から外し、全47県を国勢調査2020年値へ統一する。
- 東京都2026年と他県2020年の混在は採用しない。

## 自動取得・集計スクリプト設計案

1. `tools/school-database/fetch_population_sources.py`
   - e-Stat APIまたは公式CSV/Excelを取得。
   - 取得URL、取得日、HTTP status、ファイルハッシュを記録。
2. `tools/school-database/generate_prefecture_population_metadata.py`
   - 都道府県コードで行を抽出。
   - 3～5、6～11、12～14、15～17、3～17を各歳から合算。
   - 分母人口と割合を計算。
   - 年齢階級しかない場合は失敗させ、按分しない。
3. `tools/school-database/test_prefecture_population_metadata.py`
   - 47県件数。
   - 各県の4区分合計 = 3～17歳。
   - 3～17歳 <= 分母人口。
   - source/reference_date/population_scope/denominator必須。
   - `estimated`, `apportioned`, `dummy` がtrueにならないこと。
