# 全国学校データベース 人口メタデータ資料調査

作成日: 2026-07-31
対象: 全国47都道府県カードへ表示する人口・校種相当年齢人口メタデータ

**最終決定（2026-07-31）: 決定C — 令和2年国勢調査 表2-1（2020年10月1日現在、日本人人口）を47都道府県共通の定義として採用。** 詳細は本文末尾「Phase A 最終決定」を参照。東京都の2026年住民基本台帳パイロット値は研究資料として保存するが、本番表示には使用しない。

## 前提

- ダミー値、推計按分、5歳階級の均等分割は採用しない。
- `data/school-database/prefecture-card-metadata.json` へ人口値は追加しない。
- 東京都パイロットは、東京都公式「住民基本台帳による東京都の世帯と人口 令和8年1月 第6表」の日本国籍住民・年齢各歳データを使用している。
- 全国展開では、東京都だけ2026年住民基本台帳、他県だけ2020年国勢調査という混在は避ける。

## 案A・B・C比較

### 案A: 最新の全国共通各歳資料を採用

- 正確性: 高い。各歳なら校種相当年齢を正確合算できる。
- 鮮度: 住民基本台帳の各年1月1日表が見つかれば高い。
- 比較可能性: 高い。
- 更新作業量: 低～中。全国表1本なら自動化しやすい。
- 再現性: 高い。
- 利用者の分かりやすさ: 高い。
- 毎年更新: 可能。

現状: 条件を満たす全国共通・最新・各歳・国籍区分付き資料は未確認。

### 案B: 各都道府県の最新公式各歳資料を個別収集

- 正確性: 県により異なる。住基実数、常住人口推計、国勢調査基礎推計が混在する。
- 鮮度: 高い県もある。
- 比較可能性: 低い。
- 更新作業量: 高い。
- 再現性: 県ごとのファイル形式差が大きい。
- 利用者の分かりやすさ: 低～中。基準日・定義差をカードで説明する必要がある。
- 毎年更新: 運用負荷が高い。

現状: 埼玉県は有力だが、茨城・栃木・群馬は推計色が強く東京都定義と合わない。

### 案C: 令和2年国勢調査で47都道府県を同一基準日に統一

- 正確性: 高い。ただし国勢調査の不詳扱いを要確認。
- 鮮度: 低い。2020年10月値。
- 比較可能性: 高い。
- 更新作業量: 中。表2-1から47県を一括抽出できる可能性あり。
- 再現性: 高い。
- 利用者の分かりやすさ: 中。「2020年国勢調査」と明示すれば誤解を抑えられる。
- 毎年更新: 不可。5年周期。

現状: 全国統一定義を優先する場合の予備案。令和7年国勢調査の人口等基本集計公開後に同等表へ更新するのが自然。

## 推奨案

現時点の推奨は次の順。

1. 案Aを継続探索する。特に e-Stat API と総務省自治行政局の住民基本台帳関連統計で「市区町村別または都道府県別・年齢各歳・日本人住民/総計」を探す。
2. 案Aが存在しないと確認できた場合、令和7年国勢調査の人口等基本集計公開を待つ。
3. すぐ全国表示を出す必要がある場合のみ、案Cとして令和2年国勢調査表2-1へ全47県を統一する。
4. 案Bは、県ごとの定義差が大きく、全国カードで比較値として並べるには注意が必要なため優先しない。

## 追加調査で確定した事実（2026-07-31 実資料確認）

以下は、e-Stat・総務省・各県の実ファイル（Excel/CSV）を実際にダウンロードし、セル内容を直接確認して得た結果。表名や検索結果の要約だけでなく、実データの列構成・数値で確認済み。

### 1. 総務省 住民基本台帳調査（全国）に「各歳」表は存在しない（確定・否定）

- 総務省プレスリリース: https://www.soumu.go.jp/menu_news/s-news/01gyosei02_02000389.html
- 実ファイル確認: `https://www.soumu.go.jp/main_content/001023713.xlsx`（令和7年1月1日現在、都道府県別・総計）を含む全国公開ファイルを直接開いたところ、列見出しはすべて「0歳～4歳、5歳～9歳、10歳～14歳、15歳～19歳…」の5歳階級であり、各歳ではなかった。
- e-Stat ファイル一覧（`https://www.e-stat.go.jp/stat-search/files?toukei=00200241&tstat=000001039591`、271ファイル）も全件「年齢階級別」であり、全国・都道府県別の各歳表は1件も見つからなかった。
- e-Stat APIの`getStatsList`によるメタ情報照会は、登録アプリケーションIDがないため認証エラーとなり実行不可（ただし実ファイルの列を直接確認する方が確実な検証方法であり、これを優先した）。

**結論: 案A（全国共通・住民基本台帳・各歳）に相当する公式資料は存在しないことを確認した。**

### 2. 令和2年国勢調査 表2-1: 実データで検証済み

- 「年齢不詳」は各歳列とは別の独立列であり、各歳への按分は一切行われていない。全県・全国で「各歳合計＋年齢不詳＝公表総数」の一致を実データで検証済み（差分0）。
- 出典ファイル自身の注記: 「平均年齢・年齢中位数は年齢『不詳』を除いて算出」「『国籍総数』は日本人・外国人の別『不詳』を含む」。
- 日本人のみの年齢不詳割合（全国 0.67%）は、国籍総数の年齢不詳割合（全国 2.3%、2020年国勢調査の回収率低下の影響が大きいとみられる）より小さく、各歳合算値の信頼性は日本人のみのほうが高い。
- 国籍区分は「国籍総数」と「うち日本人」の2区分のみで、「外国人」の独立列はない（外国人人口が必要な場合は減算で導出するが、その差分には国籍不詳分も混入する）。

**結論: 案C（令和2年国勢調査 表2-1）は47都道府県すべてで単純合算可能なデータとして実証済み。**

### 3. 令和7年国勢調査 人口等基本集計の公開時期（未確定のまま）

- 総務省統計局の公表予定表では「人口等基本集計」は「令和8年9月迄」とのみ記載されており、日付までは特定できなかった。
- 令和2年国勢調査では、表2-1相当は人口等基本集計の一括公表（2021-11-30）に含まれていたため、令和7年も同様のタイミングで各歳×国籍表が含まれる可能性が高いと推測されるが、これは前例からの推測であり、公式に確約された情報ではない。

**結論: 2026年9月時点で令和7年版の各歳×国籍表が実際に含まれるかは、その時点で改めて確認する必要がある。**

### 4. 埼玉県: 実CSVで確認

- 実ファイル: `https://www.pref.saitama.lg.jp/documents/194315/ken-nenreikakusai08-2.csv`
- 行ラベルが「人口　総数０歳（人）」等であり、日本人のみではなく総数（外国人含む）であることを実データで確認。令和7年列の合計7,374,298人は、別途確認した日本人7,116,648人＋外国人257,650人の合計と一致。
- 基準日は毎年1月1日、住民基本台帳ベース。日本人のみの各歳系列は別途存在しない。

### 5. 神奈川県・千葉県: 実ファイルで確認

- 神奈川県 実ファイル: `https://www.pref.kanagawa.jp/documents/12035/r7_1hyou.xlsx`（第1表）。各歳の行は実在（年齢3歳=60,817人等）が、総数/男/女の列のみで日本人/外国人の区分列がない。ページ本文に「国勢調査結果を基礎に、住民基本台帳法・戸籍法による異動人口を加減した推計」と明記があり、住民基本台帳の実数ではなく推計値。
- 千葉県: 第2表が各歳データを含むことは確認したが、国籍区分の明記なし。基準日は令和7年4月1日であり、埼玉県（1月1日）・国勢調査（10月1日）と基準日の慣行自体が異なる。

**結論: 案B（県別個別資料）は、国籍区分・推計/実数・基準日のいずれも県ごとに不統一であることが実データで確認された。**

## Phase A 最終決定

**決定C を採用する。**

47都道府県すべてについて、**令和2年国勢調査 表2-1（2020年10月1日現在、日本人人口）** を全国統一の人口定義として採用する。

採用理由:

1. 案A（全国共通・住民基本台帳・各歳）は総務省の実ファイルを直接確認した結果、存在しないことを確定した。
2. 案Bは埼玉・神奈川・千葉の実ファイルを確認した結果、国籍区分・推計/実数の別・基準日のいずれも県ごとに不統一であり、47都道府県を同一基準で並べるには不適切であることを確認した。
3. 案Cは47都道府県すべてで「日本人人口」「年齢各歳」「年齢不詳を按分せず分離」という同一定義・同一基準日（2020-10-01）のデータが存在し、5県のサンプル実測で3～17歳・3～5・6～11・12～14・15～17歳の単純合算が正確に一致することを確認した。
4. 東京都の2026年住民基本台帳パイロット値と他46都道府県の2020年国勢調査値を混在させることは、本調査の前提（東京都2026年住基と他県2020年国勢調査の混在は禁止）に反するため採用しない。

したがって、東京都についても2026年住基パイロット値を全国表示からは外し、他46都道府県と同じ2020年国勢調査・日本人人口値に置き換える。

保留とした案（今後の更新方針）:

- 令和7年国勢調査の人口等基本集計（公表予定: 2026年9月まで）で表2-1相当の各歳×国籍表が公開され次第、全47都道府県を一括して当該データへ更新する。公開時期・収録内容は2026年9月以降に改めて確認する。
