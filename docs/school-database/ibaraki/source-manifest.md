## 最重要: 学校名の正式名称化について

山梨県版（[[project_school_database_yamanashi_v1]]、PR #68/#69）で、原本Excelの
「学校名」列が略称（例:「三の丸」「梨大附属」）だったのをそのまま収録してしまい、
利用者から訂正を受けた経緯がある。茨城県公式Excelも同様に「学校名」列が
略称（例:「三の丸」「日立第一」「盲学校」）であることを着手直後に確認したため、
今回は変換スクリプト（`convert_ibaraki_sources.py`）内で

```
設置者（市町村名／「茨城県」／「国立大学法人茨城大学」） + 略称 + 校種サフィックス
```

の組み立てルールで正式名称を構築している。構築後の名称は下記の実例についてWeb検索で
裏取り済み（すべて実在を確認）。

| 原本の略称 | 構築した正式名称 |
| :--- | :--- |
| 三の丸（水戸市立小） | 水戸市立三の丸小学校 |
| 第一（水戸市立中） | 水戸市立第一中学校 |
| 高萩清松（県立高全日制） | 茨城県立高萩清松高等学校 |
| 勝田（県立中等） | 茨城県立勝田中等教育学校 |
| 日立第一高等学校附属（県立中） | 茨城県立日立第一高等学校附属中学校 |
| 盲学校（県立特支） | 茨城県立盲学校 |
| 日立特別支援学校（市町村立特） | 日立市立日立特別支援学校 |
| 国田（市町村立義務教育学校） | 水戸市立国田義務教育学校 |
| 中里小中学校（市町村立義務教育学校、原本表記がすでに完全） | 日立市立中里小中学校（サフィックス重複を回避） |

構築ルールの詳細（略称がすでに「学園」「小中学校」等で終わる場合はサフィックスを
重ねて付けない、等）は `convert_ibaraki_sources.py` の `build_official_name()` を参照。

## 原本一覧

### 公立（茨城県教育委員会、基準日 令和7年5月1日）

- 出典ページ: https://kyoiku.pref.ibaraki.jp/about/survey/school-list/
- ファイル: `public_school_list.xlsx`（12シート: 市町村教育委員会一覧/国立/県立中(附属)/
  県立中等/県立高全日制・定時制・通信制/県立特支/市町村立小・中・義務教育学校・特別支援学校）
- 令和7年12月26日までの訂正（龍ケ崎市立大宮小学校の削除、美浦村の小学校統合）を反映済みの版。

### 私立幼稚園（茨城県福祉部子ども未来課、基準日 令和7年4月1日）

- 出典ページ: https://www.kids.pref.ibaraki.jp/kids/nursing02_1/
- ファイル: `private_youchien.pdf`
- 学校名はすでに正式名称（略称化は確認されなかった）。

### 私立小学校・中学校・中等教育学校（茨城県教育委員会）

- 出典ページ: https://kyoiku.pref.ibaraki.jp/gakko/private-schools/elementary-junior-high-school/
- ダウンロード可能なxlsx/pdfが無く、ページ本文のHTML表をそのまま
  `private_elementary_junior_secondary.json` へ書き起こした（2026-07-27時点の掲載内容）。
- 学校名はすでに正式名称。

### 私立高等学校（茨城県教育委員会）

- 出典ページ: https://kyoiku.pref.ibaraki.jp/gakko/private-schools/high-school/
- 同様にダウンロード可能なファイルが無いため `private_high_school.json` へ書き起こした。
- 全日制24校・通信制11校・特区2校の一覧。同一校が全日制・通信制の両方に掲載されている場合、
  所在地が同一なら1レコードへ統合しcourseへ両方保持する。所在地が異なる場合
  （例: 土浦日本大学高等学校の通信制キャンパスは全日制と別所在地）は別レコードのまま保持する。

## 収録対象外・注記

- 私立の「幼保連携型認定こども園」「幼稚園型認定こども園」一覧（子ども未来課）は、
  今回のスコープでは幼稚園（純粋な私立幼稚園一覧）のみを対象とし、含めていない。
- 私立各種学校・専修学校は他県版と同じくスコープ対象外。
- 公立幼稚園はスコープ対象外（他県版の運用と同様、原本の公立学校一覧にも公立幼稚園の
  掲載シートが存在しないことを確認済み）。

## 市町村表示順

市部（32市、県公式サイト掲載順）→ 郡部（10町2村、郡ごとにグルーピング）。
政令指定都市・特別区は無いため、区の扱いは不要。

## 品質基準（既存県版を継承）

- 学校名、住所、郵便番号、電話番号は推測で補わない。ただし略称→正式名称の展開は
  設置者+校種という機械的なルールで行い、個別の学校ごとに公式サイトを確認する
  作業は今回は行っていない（件数が多いため）。学校名に疑義がある場合は
  `tools/school-database/ibaraki_conversion_warnings.json` で確認できる。
- 公式HP（website）は、今回の初期変換では確実に判定できるものがないため全件空欄。
