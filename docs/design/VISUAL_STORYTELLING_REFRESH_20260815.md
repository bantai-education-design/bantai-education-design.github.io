# Visual Storytelling Refresh — 2026-08-15

## 目的
文字中心で硬く見える試作ハブを、実際の製品画面・成果物・図解を主役にした視覚的な体験へ改修する。

## 対象
- `index-new.html`
- `products/categories/index.html`
- `for-teachers/index.html`
- `for-parents/index.html`
- `databases/index.html`

## デザイン原則
1. 最初に画像・図解を見せ、説明文は短くする。
2. 商品は「名称」より「できること」が先に伝わる構成にする。
3. 先生向けは学校現場、家庭向けは学びと暮らし、DBは検索・地図・データの世界観を分ける。
4. 既存の黒・金・白を軸に、紙・木・アイボリー系の温度を加える。
5. DBは商品カテゴリーに含めず独立した柱として扱う。
6. 新規ハブは正式公開前のため `noindex, nofollow` を維持する。
