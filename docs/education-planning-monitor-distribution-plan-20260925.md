# 教育計画システム 無料モニター配布・公式HP実装計画

更新日: 2026-09-25

## 1. 基本方針

- 無料モニター版は「公式HPから直接ダウンロード」＋「Vectorからダウンロード」の2経路で配布する。
- BOOTHは製品版専用とする。
- 公式HP版とVector版は同一ZIPを使用し、ファイル名だけでなくSHA-256まで一致させる。
- 大容量ZIPはGitリポジトリ本体へコミットせず、GitHub Releasesのrelease assetとして配布する。
- アプリ本体のソースリポジトリはPrivateのため、一般利用者向けRelease assetsは **Publicの公式HPリポジトリ `bantai-education-design/bantai-education-design.github.io` のReleases** に置く。PrivateリポジトリのRelease URLを利用者向けダウンロード先にはしない。
- 統合版モニターは専用の大容量ZIPを作らず、教務支援システム＋週案システムの2本を組み合わせて利用する。
- 公式HPの見出しに固定版番号を入れず、「無料モニター版ダウンロード」を恒久見出しとする。版番号は配布ファイル・Release metadataで管理する。

## 2. 対象製品

### 通常版系
1. 教務支援システム 単体版
2. 週案システム 単体版
3. 教育計画作成・運営システム 統合版
   - モニター版は教務支援＋週案の2本構成
   - 製品版はBOOTHで販売

### 調整授業時数対応版
4. 調整授業時数対応版
   - 公式HPから無料モニター版を直接ダウンロード可能にする
   - Vector掲載も併用する
   - マニュアルを添付
   - 将来の製品版販売導線へつなげる

## 3. 配布先の役割

- 公式HP: モニター版の紹介・直接ダウンロード・マニュアル・SHA-256・FAQ・製品版導線
- GitHub Releases: Publicの公式HPリポジトリ上で、大容量ZIP・PDFマニュアル・SHA256SUMS.txtの実体を保管・公開
- Vector: 無料モニター版の外部配布・認知拡大
- BOOTH: 製品版のみ販売
- Google Drive: 非公開バックアップのみ。利用者向け配布には使用しない

## 4. 利用期限

- 通常版系モニター: 2027-03-31
- 調整授業時数対応版モニター: 2027-08-31

## 5. ライセンス・通信説明

### 無料モニター版
- モニター期間中はシリアル登録不要で利用できる構成とする。
- 通常版系は2027-03-31まで、調整授業時数対応版は2027-08-31まで。
- ダウンロード時のみインターネット接続が必要。通常利用はオフライン可能。
- 業務データはPC内に保存する。

### 製品版
- 初回のシリアル認証にはインターネット接続が必要。
- 認証完了後の通常利用はオフライン可能。
- 製品版は買い切り。
- 購入者本人のWindows PC 2台まで。
- 同一PCの再インストール・更新は、安定した端末IDが維持される限り同一端末として扱う。
- PC買い替え時は旧端末登録を管理者側で解除する。

## 11. GitHub容量方針

- 通常Gitリポジトリに100 MiB超のZIPを置かない。
- 大容量ZIPはPublicの公式HPリポジトリのGitHub Releasesに置く。
- release assetは1ファイル2 GiB未満を守る。
- SHA256SUMS.txtを同梱する。
- リポジトリ本体にはHTML/CSS/JS/JSON/画像等のみを置く。
- 画像はWebP/JPEG/PNGを最適化して使用し、不必要な巨大画像は置かない。

## 12. 実装手順

### STEP 1 配布物確定
- 教務支援の最新モニターZIP
- 週案の最新モニターZIP
- 調整授業時数対応版の最新モニターZIP
- 各マニュアル
- バージョン
- Git commit SHA
- ファイルサイズ
- SHA-256

### STEP 2 GitHub Releases
- Publicの `bantai-education-design/bantai-education-design.github.io` に配布専用Releaseを作成
- Privateのアプリリポジトリで検証・ビルドした確定ZIPだけをRelease assetとして添付
- PDFマニュアル添付
- SHA256SUMS.txt添付
- release notesに製品名・版・ビルド元commit SHA・ファイルサイズ・SHA-256・利用期限を記録
- PrivateアプリリポジトリのActions artifactは検証・受け渡し用であり、一般利用者向け恒久URLには使用しない

### STEP 3 公式HP
- monitor-downloadページ作成
- adjusted-curriculumページ作成
- 教育計画総合ページから導線追加
- 公式HP直DL・Vector・BOOTH・マニュアルの4系統を明確化
- SHA-256・更新日を表示

### STEP 4 Vector
- 旧「登録後にライセンスキー」等の説明を削除
- 旧BOOTHモニターURLを削除
- 公式HPからもDL可能と案内
- 公式HP版とVector版が同一ZIPであることを明記

### STEP 5 最終検証
- 公式HP直DL
- Vectorリンク
- BOOTHリンク
- マニュアルリンク
- ZIPのSHA-256一致
- 旧URL残存
- 旧版番号固定表示残存
- モバイル表示
- GA4 download event
