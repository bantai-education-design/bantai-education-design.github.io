# 週刊教育ニュース・コラム自動生成＆定期実行ガイド

Ban.Tai Education Design 公式HPにおける「週刊教育ニュース・特記事項解説コラム」の自動収集・投稿タスクの定期実行仕様書およびマニュアルです。

---

## 1. 定期実行タスクの概要

- **実行スケジュール**: 毎週月曜日 09:00 AM (Cron: `0 9 * * 1`)
- **タスクID**: `b6f4fd4e-e888-47c0-8861-e73cd577da74/task-2533`
- **対象カテゴリー**: `教育動向` (`trends`)

---

## 2. 定期実行ワークフロー（自動処理手順）

1. **最新教育ニュースの収集 (Web検索)**
   - 過去1週間（直近7日間）の文部科学省の報道発表、GIGAスクール・ICT活用、生成AIの学校利用、教員の働き方改革、探究学習、大学入試関連ニュース等を収集。
2. **ニュースダイジェスト・特記事項の抽出**
   - 収集されたニュースを項目別に一覧化し、その中から今週最も重要な「特記事項（注目のテーマ）」を1〜2件選定。
3. **コラム本文の執筆・フォーマット**
   - 元小中学校教員（現場指導40年）の視点を交えた、現場に役立つ考察と解説を付加して Markdown 形式で原稿を作成。
4. **アイキャッチ用サムネイル画像の自動生成**
   - `generate_image` ツールを用いて高品質なイメージ画像を生成し、`assets/images/columns/weekly-education-news-YYYYMMDD.webp` に保存。
5. **JSONデータ登録**
   - `scripts/weekly_education_news_column.py` を使用して `data/columns.json` の最上部に新着記事（`date: YYYY.MM.DD`）として登録。
6. **画面表示テスト (Playwright)**
   - トップページの「NEW 新着」カード表示、コラム一覧、詳細モーダル表示を自動テスト。
7. **Git Pull Request & CIマージ**
   - フィーチャーブランチを作成してコミット・Pushし、GitHub PR作成からCIチェック通過の上 `main` へマージ。

---

## 3. 手動実行コマンド

任意のタイミングで即時実行したい場合は、以下のSlash Commandまたは自然言語リクエストで使用できます。

```text
/schedule 過去1週間の教育ニュースを収集して公式HPに新しい週刊コラム記事を今すぐ投稿して
```
