# 書籍2冊改訂に伴う公式HP・関連コラム監査（2026-10-18）

## 目的と保全
改訂済みの2冊について、改訂後の**入稿最終原稿・KDP登録情報**を唯一の書誌根拠としてサイト掲載内容を検証する。未確認の版、ページ数、特典、目次、紙版発売、アプリ機能を推測で断定しない。旧コンテンツは保全し、承認まではmainにマージしない。

## 対象
- `/books/`（元データ `data/product-details/books.json`、生成物 `books/index.html`）
- `/books/hogosha-bunrei/`、`/books/hogosha-bunrei/tokuten/`
- `/books/school-schedule-changes/`
- `/columns/next-curriculum-info-ai-20260926/` および書籍紹介・商品リンクが登場するコラム（全文検索で洗い出す）

## 既存表示で見つかった確認ポイント
1. 両書籍とも一覧バッジは「発売中 Kindle版」。紙版の発売・改訂の状況をKDPで別々に確認する。
2. 保護者文例集は一覧・詳細とも「121場面」、7章＋付録、ダウンロード特典と無料試読版を案内。改訂最終原稿、特典配布物、BOOTHリンクとの突合せが必要。
3. 時間割本は一覧で「年間計画→時間割→週案→実績→提出資料」、詳細ページで「対応アプリで確かめられる」と明記。実際に収録された内容とアプリの公開済み機能を確認し、未実装の連携があれば表現を修正する。
4. 時間割本の説明はGoogle Driveの2026-10-12付「学校の時間割が変わる_KDP商品説明改訂案・Antigravity差替え依頼_20261012」と軸が異なる。この文書は**候補案**であり、KDP掲載済みの最終情報ではない。
5. 次期学習指導要領関連コラムは制度解説であり、書籍改訂と別の一次資料確認を要する。制度の確定事項と検討事項を区別して保持する。

## 本PRの変更
書籍一覧の「刊行について」は片方の書籍だけを説明していたため、二冊の改訂照合中である旨の共通案内に変更。読者特典の説明は対象書籍を明記。正本JSONと生成HTMLを同時更新。
