## 4. ソフト詳細説明文（長文 / Vector登録画面の「詳細説明」へそのまま貼り付け可能）

【本ソフトの概要と開発の背景】
文部科学省および中央教育審議会において、児童の主体的・対話的で深い学びの実現や、学校現場の負担軽減・柔軟な教育課程編成を目的として検討が進められている「授業時数の見直し・調整授業時数制度」に対応した、小学校教育計画作成・運営システムの特別先行エディションです。

本制度は、2028年度（令和10年度）の全国先行実施、2030年度（令和12年度）の小学校全面実施が予定されています。全国の本格導入に先駆け、各学校が独自の時間割や配当時数をもとに、どの教科の時数を何時間削減し、探究学習等へどう振り替えられるのかを事前に試算・検証（シミュレーション実習）いただけます。

※利用時間の制限（15分で終了するお試し体験版など）は一切ありません。モニター利用期限である「2027年8月31日まで」、入力・編集・保存・印刷・PDF出力・Excel/JSON出力などのすべての機能を何度でも無制限にご利用いただけます。


【学校現場でどれだけ役に立つのか：圧倒的な6大実務支援機能】

1. ゼロから作らない「教科書・年間指導計画の取込アシスタント」
年度初めの計画作成は教務にとって膨大な負担です。本ソフトは、正規に入手した教科書会社・教育委員会等の年間指導計画（ExcelやPDFの表）をコピー＆ペーストするだけで、タブ・カンマ・空白を自動判定して単元配列や配当時数を取り込みます。教務がゼロから単元名や時数を打ち込む必要はありません。

2. 削減・充当の自動バランス計算と警告表示
各教科の縮減時数と、探究学習や総合、独自教科への充当時数をリアルタイムで自動集計。削減超過、充当不足、未解決の端数など、教育課程の不整合があれば即座に画面上で警告し、計算ミスや確認漏れを防ぎます。

3. 15分単位のモジュール授業（1/3コマ、2/3コマ）に完全対応
1コマ（45分）を3ユニットとし、15分授業を「1/3コマ（1ユニット）」、30分授業を「2/3コマ（2ユニット）」として精密に管理。通常の授業コマとモジュール授業が混在する複雑な時間割でも、時数計算が破綻しません。

4. 年間計画から日々の週案・授業実績・提出書類まで一気通貫
単なる時数シミュレーション表にとどまりません。教務が組んだ年間の調整計画を各担任の週案へそのまま自動展開し、毎日の授業実績の記録、月別・学期別・年間の時数累計、教務提出用の各種書類印刷まで一つの流れで完結します。

5. 学校の実務に即した多彩なデータ取込口
前年度の計画データ（JSON形式）の引継ぎ、年間行事予定（PDF・Excel・CSV・テキスト貼付・画像参照）、学校の基本時間割（Excel・CSV読込み）に対応。教科・学年ごとの教科書会社採択設定も自在に行えます。

6. 現行システムとの安全な共存設計（既存データを壊さない）
現在学校で通常運用されている標準教育計画システム（通常版）がインストールされているパソコンでも、既存データや設定を一切上書き・破損することなく、完全に分離された保存先で安全に並行利用できることを実機検証済みです。


【安心・安全への配慮】
- 完全オフライン動作可能：日々のデータ入力や計画管理はすべてパソコン内にローカル保存されます。児童生徒の個人情報や学校の内部情報がインターネット上に送信される心配はありません。
- 著作権の遵守：著作権保護のため、教科書の本文、画像、図表、単元データそのものはアプリ内に無断同梱していません。学校や先生が正規に入手された資料の表データを安全に取り込んでご活用いただく設計です。
- 改ざん防止・完全性確認：配布ZIPファイルにはSHA-256ハッシュ値を公開し、安全性と完全性を担保しています。
