【本ソフトの概要】
文部科学省で議論されている「調整授業時数制度」（2028年度全国先行実施・2030年度小学校全面実施予定）に対応した特別先行エディションです。教務の年間調整計画と担任の週案作成・実績集計が最初から連動するオールインワン設計です。
※15分の体験版等ではなく、2027年8月31日までシリアル登録不要で全機能を無制限にご利用いただけます。

【学校現場でどれだけ役に立つのか：実務支援の核心】
1. ゼロから作らない「年間指導計画の取込アシスタント」
正規入手した教科書会社等の年間指導計画表をコピペするだけで、タブやカンマを自動判定して単元配列や配当時数を取り込みます。教務がゼロから手入力する手間を排除します。

2. 削減・充当の自動バランス計算と警告表示
各教科の縮減時数と探究学習等の充当時数をリアルタイム自動集計。削減超過、充当不足、未解決端数などの不整合を即座に画面警告し、計算ミスを防ぎます。

3. 15分単位のモジュール授業（1/3コマ、2/3コマ）に完全対応
1コマ45分を3ユニットとし、15分（1/3コマ）や30分（2/3コマ）の授業を精密管理。通常コマとモジュールが混在しても時間割や時数計算が破綻しません。

4. 年間計画から週案・実績集計・提出書類まで一気通貫
教務が組んだ年間の調整計画を各担任の週案へ自動展開。日々の授業実績記録、月別・学期別・年間の時数累計、教務提出用の各種書類印刷まで一つの流れで完結します。

5. 多彩なデータ取込と安全な共存設計
前年度JSON引継ぎ、年間行事予定、基本時間割の取込に対応。現在運用中の標準版（通常版）のデータ保存先とは完全に分離しており、既存データを壊さず安全に同じPCで並行利用できます。

【安心のセキュリティと動作環境】
・完全オフライン対応：業務データはPC内にローカル保存され、外部送信されません。
・著作権配慮：教科書本文等の実データは同梱せず、学校正規入手資料を取り込みます。
