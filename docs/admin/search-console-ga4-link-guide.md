# Ban.Tai Education Design — Search Console・GA4連携手順書

## 1. 概要

本手順書は、Google Search Console（検索キーワード、表示回数、クリック数）と Google Analytics 4（GA4: `G-KPGJ0R2KXR`）を連携し、検索流入からサイト内行動までを一元的に分析できるようにするための手順書です。

> [!NOTE]
> 本連携の設定には、Search Console のプロパティ所有権と、GA4 プロパティの編集者以上の権限を持つ Google アカウントによる認証操作が必要です。

## 2. 前提条件

1. **対象ドメイン**: `https://bantai-education-design.github.io/`
2. **Search Console プロパティ**: 上記URLプレフィックスまたはドメインプロパティが登録済みであること。
3. **GA4 測定ID**: `G-KPGJ0R2KXR`

## 3. 連携手順（管理画面での操作）

### ステップ 1: GA4管理画面を開く
1. [Google アナリティクス](https://analytics.google.com/) にサインインします。
2. 左下の歯車アイコン（**管理**）をクリックします。

### ステップ 2: Search Console リンクの作成
1. 「サービス間のリンク」列にある **「Search Console のリンク」** を選択します。
2. 画面右上の **「リンク」** ボタンをクリックします。
3. **「アカウントを選択」** をクリックし、連携する Search Console プロパティ（`https://bantai-education-design.github.io/`）を選択して「確認」をクリックします。
4. **「次へ」** をクリックします。
5. **「ウェブストリームを選択」** をクリックし、本サイトのデータストリーム（`G-KPGJ0R2KXR`）を選択します。
6. 設定内容を確認し、**「送信」** をクリックします。
7. 「リンクが作成されました」と表示されたら連携完了です。

### ステップ 3: GA4レポートメニューへの公開
1. GA4左メニューの **「レポート」** をクリックします。
2. 画面左下の **「ライブラリ」**（本棚のアイコン）をクリックします。
3. コレクション一覧にある **「Search Console」** カードを探します。
4. 右上の縦の3点リーダーメニューから **「公開」** を選択します。
5. 左メニューに「Search Console」（「検索クエリ」および「Google オーガニック検索トラフィック」）が追加されます。

## 4. 分析・確認項目

連携完了後、以下のレポートが確認可能になります：
- **検索クエリ**: サイトがどのような検索キーワードでGoogle検索結果に表示され、クリックされたか。
- **ランディングページ**: 検索流入ユーザーが最初に閲覧したページと、その後のエンゲージメント時間、主要イベント（BOOTH遷移、無料ダウンロード、コラム閲覧等）の発生状況。
