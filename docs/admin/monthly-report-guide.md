# Ban.Tai Education Design — GA4月次レポート作成手順書

## 1. 目的

本手順書は、Google Analytics 4（GA4）の計測データをもとに、月次のサイト運営実績を客観的かつ正確に集計・報告するための標準手順を定めます。

## 2. 集計用語と表現の厳格な統一

正確な事実把握のため、報告書では以下の表現基準を厳守します。

| 推奨される正しい表現 | 使用を禁止する不正確な表現 | 理由 |
|---|---|---|
| **GA4で計測されたアクティブユーザー数** | 訪問者の実数 | ブラウザのCookie規制や同一人物の複数端末利用があるため |
| **ダウンロードリンクのクリック数** | ダウンロード人数 | 同一ユーザーの複数回クリックや中断が含まれうるため |
| **BOOTHへの移動数** | BOOTH購入者数 | 外部販売サイトでの最終決済完了数とは異なるため |
| **モニターフォームへの移動数** | モニター応募者数 | フォーム到達後の送信完了数とは異なるため |
| **一定時間閲覧** | 完了と断定する表現 | 画面を開いたまま離席した場合等との厳密な区別が困難なため |

## 3. 月次集計対象指標

### 3.1 サイト全体指標
1. **GA4で計測されたアクティブユーザー数**: 月間にサイトへアクセスしたアクティブユーザーの合計。
2. **表示回数（ページビュー数）**: 全ページの閲覧総数。
3. **平均エンゲージメント時間**: ユーザーが実際にページを前面で閲覧していた平均時間。

### 3.2 製品・導線別指標
1. **ダウンロードリンクのクリック数**: GA4拡張計測の `file_download` イベント数。
2. **BOOTHへの移動数**: `booth_click` イベント数。製品名（`product_name`）別の内訳を集計。
3. **モニターフォームへの移動数**: `monitor_form_click` イベント数。
4. **ライセンス申請フォームへの移動数**: `license_form_click` イベント数。

### 3.3 コラム利用指標
1. **コラム閲覧数**: `column_view` イベント数。記事タイトル別の内訳。
2. **コラムの一定時間閲覧数**: `column_engagement` イベントのうち、`is_engaged = true`（閲覧時間15秒以上）の件数。
3. **記事内アクション数**: `column_next_action` イベント数。

## 4. GA4探索レポートでの集計手順

1. **GA4管理画面へのアクセス**: [Google アナリティクス](https://analytics.google.com/) へサインインし、プロパティ `G-KPGJ0R2KXR` を選択します。
2. **対象期間の設定**: 左メニュー「探索」または「レポート」から、前月1日〜前月末日を期間指定します。
3. **内部トラフィックの除外確認**: 本人除外（`bantai_ga_disable`）およびIPフィルタが有効になっていることを確認します。
4. **イベント別集計**:
   - ディメンション: `イベント名`, `item_name` または `product_name`
   - 指標: `イベント数`, `総ユーザー数`
5. **コラムエンゲージメント集計**:
   - イベント名 `column_engagement` でフィルタを作成。
   - ディメンション: `column_title`, `is_engaged`
   - 指標: `イベント数`
   - `is_engaged = true` の行を「一定時間閲覧数」として記録。
