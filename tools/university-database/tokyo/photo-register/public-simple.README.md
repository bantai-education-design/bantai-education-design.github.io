# 一般投稿の簡易フロー

一般投稿者は `public-simple.html` を使用し、大学名・写真・投稿確認だけで送信する。写真編集、メイン写真選択、トリミング、傾き補正、明るさ補正は投稿者に行わせず、Ban.Tai管理側で行う。

`submission-runtime-config.json` が `enabled=true`、`mode=remote`、HTTPS `endpoint` 設定済みの場合のみ送信ボタンを有効化する。未接続時はUI確認だけ可能で、送信は行わない。

送信成功後は、確認後掲載すること、掲載写真は固定ではなく新しい投稿を見ながら不定期に追加・更新することを案内する。
