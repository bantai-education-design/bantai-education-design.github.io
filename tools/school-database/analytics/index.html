本データ・統計指標についての注意事項と出典

  • 総人口・年齢別人口（6〜11歳、12〜14歳等）: 総人口は外国籍を含む総務省統計局「令和2年国勢調査（2020年10月1日現在）」の総人口に基づきます。年齢別人口は各指標の定義・出典（e-Stat / 国勢調査）を参照してください。
  • 学校数（小学校数・中学校数・全校数）: Ban.Tai 全国学校データベース（2026年9月現在）の収録データに基づきます。
  • 教員数・児童生徒数: 文部科学省「学校基本調査」（令和7年5月1日現在）の公表値に基づきます。
  • 独自換算指標（1校あたり学齢人口）: 各都道府県の学齢人口を当該学校数で除して求めた参考指標であり、地域における学校配置規模や需要の目安を示すものです。本数値は順位付けや教育水準の評価を意図するものではありません。
