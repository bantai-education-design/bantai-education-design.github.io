# 運動会の風景が変わった――学校現場の40年を振り返って

　運動会の季節も、そろそろ終わりです。私は40年にわたって学校現場に関わる中で、この行事の風景が少しずつ変わるのを見てきました。

　以前は万国旗が校庭を彩り、昼には親子で弁当を囲み、午後二時、三時頃まで競技が続くことも珍しくありませんでした。運動会は学校の行事でありながら、家族や地域にとっても、お祭りのような一日だったのです。

　近年、私が見てきた範囲では、昼食を挟まず午前中で終了する形が増えています。少し寂しくもありますが、昔に戻せばよいとは思いません。暑さや家庭の事情、学校の負担など、取り巻く条件が変わっているからです。

　運動会は、本番の数時間だけでは成り立ちません。計画、教職員と児童の係分担、テントの設営、ライン引き、ロープ張り、用具の準備、受付。終われば片付け、翌年も使えるように保管します。例年の計画を引き継いでも、今年の子どもたちに合わせた確認は必要です。

　子どもたちにも、覚えることがたくさんあります。徒競走でさえ、走るだけではありません。並ぶ場所、出る順番、スタートの合図、走り終えた後の動き。安全に進めるには、実際に動いて確かめる時間が欠かせません。

　特に表現運動は、振付、音楽、立つ位置、隊形移動を覚えます。教える先生にはおなじみでも、初めて踊る子どもには新しいものです。全体を通す予行練習を省き、部分的な確認で進める場合もありますが、練習を減らすなら、手順や内容も整理しなければなりません。

　定番の南中ソーランが広まる姿にも、学校の事情が見えます。指導した先生が異動先へ伝え、そこで一緒に取り組んだ先生が、さらに次の学校へ伝える。私が見てきた普及の経路の一つです。

　学校独自の工夫や、子どものアイデアがもっとあってもよいと思います。ただ、新しい演目を考え、指導方法を組み立てる時間は限られています。「経験があり、見通しを持てるものにしよう」という判断には、忙しい現場なりの理由があります。

　安全への配慮も、以前より深く考えるようになりました。私の経験には、参観者が体調を崩し、救急搬送されたこともあります。熱中症対策は児童と教職員だけの問題ではありません。保護者や地域の方々まで含めて、休憩や日陰、救護の体制を考える必要があります。

　昼食の時間も同じです。家族で弁当を囲む光景は懐かしいものですが、保護者が来られない子どもや、保護者と離れて暮らす子どももいます。昔の楽しさを語るとき、その場で寂しさを感じていた子どもがいなかったかも、忘れずに考えたいと思います。

　それでも、運動会には人をつなぐ力があります。終了後、保護者が率先してテントを片付けてくれる姿には、いつも支えられてきました。一方で、地域の付き合い方や働き方は変わり、誰もが長い時間集まれるわけではなくなっています。

　お祭りのようなにぎわいが薄れることに、寂しさはあります。ただ、華やかさを取り戻すことだけが答えではないのでしょう。日常の学習を生かし、無理なく参加できる、落ち着いた行事として整えていく。その中で、学校と家庭、地域がつながれる方法を探したいと思います。

　かつて走り、踊った子どもたちは、やがて応援する大人になります。自分の思い出を大切にしながらも、今の子どもに合う形を考える。残したい経験と、変えてよい方法を分けて考えることが、これからの運動会につながるのではないでしょうか。

　運動会の起源から、徒競走・団体競技・表現運動、準備や練習の負担、午前開催、地域とのつながりまで、詳しくはコラムにまとめました。学校現場で見聞きしてきたことを交えながら、運動会の変化を振り返っています。ご自身の思い出や、今の学校の姿と重ねて読んでいただければ幸いです。
