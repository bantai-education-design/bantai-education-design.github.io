一太郎年表

「jX-WORD太郎」から「一太郎2026」へ

――バージョンアップでたどる日本語ワープロ41年史

一太郎の歴史は、単に毎年新しいワープロが発売された歴史ではない。

日本語入力、文節変換、GUI、Windows、インターネット、電子書籍、スマートフォン、音声認識、そして生成AI。

その時代ごとに、「日本語をコンピューターでどう扱うか」という課題に向き合ってきた歴史でもある。

ここでは前身の「jX-WORD太郎」から一太郎2026までを、主要なバージョンアップ内容とともに年ごとにたどってみる。

1983年JS-WORD――一太郎以前の出発点

ジャストシステムが日本語ワープロ「JS-WORD」を開発。

まだパソコンで日本語を扱うこと自体が難しかった時代で、漢字表示、日本語入力、印刷までを一体として実現する必要があった。

日本語入力には、後のATOKにつながる「KTIS」が使われた。

この年の意味

一太郎の歴史は、ワープロ画面の設計よりも前に、「コンピューターで日本語そのものを扱う」技術から始まった。

1984年jX-WORD

IBM JX向けの日本語ワープロ「jX-WORD」を発売。

日本語入力システムも改良され、翌年の「太郎」シリーズへつながる土台が整う。

バージョンアップのポイント

  • 日本語処理能力の向上
  • GUI的な操作への挑戦
  • 日本語入力システムの改良
  • PC機種への最適化

1985年2月jX-WORD太郎

PC-9801向けに「jX-WORD太郎」を発売。

ここで初めて「太郎」の名前が登場した。

日本語入力にはATOK3を搭載。

バージョンアップのポイント

  • NEC PC-9800シリーズへ対応
  • 日本語ワープロとしての操作体系を確立
  • ATOKとワープロ本体を組み合わせた環境を構築

1985年8月初代「一太郎」

製品名を「一太郎」として発売。

価格は58,000円。

日本語入力システムはATOK4。

当時10万円を超えるワープロソフトも珍しくなかったため、58,000円はかなり戦略的な価格だった。

バージョンアップのポイント

  • スペースキーによるかな漢字変換
  • 文節を意識した日本語入力
  • ATOKを他のアプリケーションでも利用できる方向へ発展
  • ワープロ本体と日本語入力環境を分離して考える思想

歴史的意味

「一太郎＋ATOK」という、後の40年間につながる基本構成がここで完成した。

1986年一太郎Ver.2

ATOK5を搭載。

PC-9801の普及とともに、一太郎の利用者も急増した。

バージョンアップのポイント

  • 日本語変換性能の向上
  • 文書編集機能の強化
  • 操作性改善
  • 印刷機能の充実

このころ

「PC-98で日本語を書くなら一太郎」という地位を固め始める。

1987年一太郎Ver.3

一太郎初期の大きな完成形。

ATOK6搭載。

バージョンアップのポイント

  • 文節単位での変換性能向上
  • 熟語変換の精度向上
  • 文書編集の安定化
  • 罫線や日本語文書特有の編集機能を強化
  • 実務で長時間使える操作性へ成熟

歴史的意味

このVer.3によって一太郎は日本の代表的ワープロへ成長した。

私自身、一太郎を本格的に使い始めたのも、このころだった。

ATOKが文章を文節ごとに判断して変換していく様子は、当時としては実に新鮮だった。

1988年Ver.3成熟期

大型の番号変更はないが、一太郎Ver.3が広く定着した時期。

改良・利用環境

  • PC-9801での利用が一般化
  • 周辺プリンターへの対応拡大
  • 辞書や日本語入力環境の充実
  • 企業・官公庁・教育現場へ普及

歴史的意味

製品としての「ヒット」から、事実上の標準的ワープロへ移っていった時期。

1989年一太郎Ver.4

ATOK7搭載。

一太郎史上、最も野心的なバージョンの一つ。

独自のウィンドウシステムJustWindowを採用した。

バージョンアップのポイント

  • DOS上にウィンドウ型操作環境を構築
  • 「花子」など他のジャストシステム製品との切り替え
  • VAF（Value Added Function）による機能追加
  • 英文スペルチェック
  • 数式作成などの拡張機能
  • EMSメモリーへの対応

問題も発生

Ver.4は新技術を多く盛り込んだ一方、発売当初は不具合も多かった。

その後、Ver.4.1、Ver.4.2、Ver.4.3と改良を重ね、安定性を取り戻していった。

歴史的意味

単なるワープロではなく、「日本語中心の独自PC環境を作る」というジャストシステムの大きな挑戦だった。

1990年Ver.4系の成熟

大型の新バージョンはない。

Ver.4系とJustWindow環境の安定化が進んだ。

主な流れ

  • Ver.4系の改良継続
  • 花子との連携
  • VAFによる拡張
  • 一太郎dashなど派生製品の利用拡大

一方で海外ではWindowsが急速に力をつけ始めていた。

1991年DOS/V時代の始まり

一太郎本体はVer.4系が中心。

しかしPC環境そのものが変わり始める。

技術環境

  • DOS/Vの普及開始
  • 日本語処理が専用ハード依存からソフトウェア中心へ
  • IBM PC互換機が日本市場へ進出

歴史的意味

PC-9801という国内独自市場を基盤としていた一太郎にとって、後に大きな転換を迫る変化だった。

1992年次世代一太郎への準備期

大型の一太郎発売はなく、次のVer.5へ向けた移行期。

技術環境

  • Windows 3.xが徐々に普及
  • GUIが一般利用者にも浸透
  • DOS中心からWindows中心へ市場が動き始める

1993年一太郎Ver.5

ATOK8搭載。

一太郎にとって非常に重要なバージョン。

バージョンアップのポイント

  • AI変換技術を導入
  • 前後の文脈を考慮したかな漢字変換
  • Windows版を展開
  • Macintosh版
  • OS/2版
  • 異なるOS間でのデータ互換を重視

ATOK8では単に直前の読みを見るのではなく、前後の文脈から適切な漢字を判断する方向へ進化した。

歴史的意味

PC-98専用文化から、複数OSへ展開する一太郎へ。

1994年Ver.5マルチプラットフォーム展開

Ver.5系を各種環境へ展開。

主な進化

  • Windowsへの適応
  • Macintosh環境への対応準備・展開
  • OS/2対応
  • ファイル互換性向上

Microsoft Wordとの競争が本格化していく。

1995年一太郎Ver.6 / Ver.6.3 / Windows 95の足音

一太郎が本格的なWindowsアプリケーションへ移行。

バージョンアップのポイント

  • GUIを全面的に刷新
  • マウス操作を重視
  • 自動入力補正「JAC」
  • 文書校正支援機能
  • グラフ作成・フォント効果
  • Macintosh版・Windows 3.1 / Windows 95への適応

そして同年11月、日本語版Windows 95が発売され、PC市場の主役は急速にWindowsへ移っていく。

1996年〜1997年一太郎7 / 一太郎8――累計1,000万本突破とWordとの本格決戦

ATOK10搭載の32bitアプリ「一太郎7」、原稿用紙印刷や日本語組版を強化した「一太郎8」が登場。

シリーズ累計出荷1,000万本を突破し、日本ワープロ史の頂点を極める。

一方、Windows＋Word＋Excelのビジネス標準化により、ファイル互換性が重視される激動の時代へ突入する。

1998年〜2003年一太郎9〜13――JTD形式・インテリジェントドキュメントプロセッサへ

JTD文書形式の採用、音声入力「Voice一太郎9」、「ナレッジウィンドウ」による情報活用支援など、単なる文字入力にとどまらない知的生産ツールへの深化を図る。

2004年〜2009年一太郎2004〜2009――「西暦名称」と「情報処理技術遺産」認定

製品名を「一太郎2004」へ変更。

アウトライン編集、Linux版展開、そして2009年には初代一太郎が「情報処理技術遺産」に認定され、日本のコンピューター史を創った金字塔として公認される。

2010年〜2015年発売25周年・30周年――「創」「承」「玄」「徹」

25周年の「一太郎2010」、30周年の「一太郎2015」へ。

「創」「承」「玄」「徹」という一文字テーマを掲げ、創作・表現、伝統継承、徹底的な日本語組版の追求へと進化を遂げる。

2016年〜2024年専門道具への昇華――縦書き・電子書籍・個人出版時代

クラウド（Googleドキュメント等）普及の中でも消えず、縦書き、日本語組版、冊子・書籍制作、電子書籍出力など、汎用Officeには真似のできない「日本語の専門道具」としての確固たる地位を確立する。

2025年〜2026年40周年、そして生成AI時代へ――一太郎2026

初代一太郎から41年目を歩む「一太郎2026」。

テーマは「伝わることば、信頼される文書。」。

1985年に「かなを漢字に変える」ことから始まったATOKは、2026年に「書いた文章をどう相手に伝えるか」をAIで支援する次元へと進化を遂げた。

私自身のパソコン史と重ねると

この年表は、私にとって単なる製品史ではない。

半角カタカナしか扱えなかったころ。

漢字ROMを使ったころ。

文字コードで漢字を呼び出したころ。

単漢字変換に驚いたころ。

管理工学研究所の「松」を気に入って使っていたころ。

一太郎Ver.3と出会い、ATOKの文節変換に驚いたころ。

学校現場にパソコンが入り始めたころ。

Wordが当たり前になったころ。

インターネットが学校へ入ったころ。

そして今、ChatGPTのような生成AIと一緒に文章を書き、Webサイトやアプリまで作る時代。

こうして並べると、一太郎41年の歴史と、私自身の約40年にわたるコンピューターとの付き合いは、かなりの部分で重なっている。

だから私は、一太郎2026を単なる「昔からあるワープロ」として見ることができない。

「日本語をコンピューターで扱う」という、かつて非常に難しかった課題に挑み続けた一つの歴史として見てしまう。

1985年。

ATOKは「かなを漢字にする」ことに挑んでいた。

2026年。

コンピューターは「文章をどう直せば、より相手に伝わるか」にまで踏み込もうとしている。

その41年間の変化を実際に見てきた者として、もう一度、一太郎を触ってみたい。

よみがえる、あの一太郎。

それは懐かしいソフトとの再会だけではない。

日本語とコンピューターが歩いてきた41年間との再会なのだと思う。
