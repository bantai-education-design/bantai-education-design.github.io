白い紙に、記憶が浮かび上がる

――押入れの暗室と、一枚の写真を育てた時間

文・磐田井｜Ban.Tai Education Design

赤い暗室灯の下に、一枚の印画紙があります。

見た目は、ただの白い紙です。けれど、その紙には、引き伸ばし機を通してネガの像が露光されています。まだ目には見えない写真が、そこに潜んでいるのです。

印画紙を現像液に静かに浸し、バットをゆっくり揺らす。しばらくすると、白かった紙に薄い影が現れます。影は少しずつ輪郭を持ち、やがて、あのとき見ていた風景へと変わっていきます。

「ああ、出てきた……」

何度経験しても、この瞬間には心が動きました。

シャッターを切った場所と、今いる小さな暗室が、一枚の紙を通してつながる。写真を撮る喜びとは少し違う、自分の手で写真を生み出す喜びがありました。

シャッターを切っても、まだ結果はわからない

フィルムで撮っていた頃、撮影した画像をその場で確認することはできませんでした。

ピントは合っているだろうか。シャッター速度は十分だっただろうか。あの表情を捉えられただろうか。

確かめられるのは、現像してからです。

一度きりの場面を撮っていても、結果がわかるまでには時間がかかる。フィルムには枚数の限りがあり、撮影にも現像にも費用がかかりました。だから、シャッターを切る前に立ち止まり、画面の隅まで確かめようとしました。

それでも、仕上がったネガを見れば、わずかなピントのずれや、動く被写体のぶれに気づくことがあります。思い描いたようには写っていない。その悔しさも、次の撮影へ持ち帰ることになりました。

今のデジタル写真には、すぐに確認し、修正しながら撮れる良さがあります。フィルムの時代には、結果を待つ時間と、失敗を後から受け止める時間がありました。

その違いは、写真に向き合う姿勢にも影響していたように思います。

押入れの上段が、私の暗室だった

私が白黒写真に夢中になった理由の一つは、撮影の後も、自分の手で仕上げられることでした。

同じネガでも、どの範囲を切り取るか、どのくらいの明るさにするか、白から黒への調子をどう整えるかによって、写真の印象は変わります。

撮って終わりではなく、その先にも表現の余地がある。それが面白かったのです。

当時、立派な作業室があったわけではありません。住んでいたアパートの押入れの上段に、引き伸ばし機を設置していました。限られた場所を工夫して使った、私だけの小さな暗室でした。

そんな私を見て、大家さんご夫婦が、思いがけないことをしてくださいました。

「磐さん、これ使いなさい」

暗室作業のために、専用の流し台を設置してくださったのです。

薬品を準備するにも、器具を洗うにも、写真を水洗いするにも、水が欠かせません。流し台が使えるようになったことは、作業のしやすさを大きく変えてくれました。

それ以上にうれしかったのは、私が夢中になっていることを理解し、支えてくださったことでした。

今は亡きお二人の優しさを、暗室の記憶と切り離すことはできません。写真歴46年を振り返ると、機材や技術とともに、あの流し台のことが浮かんできます。

長尺フィルムを、自分で詰めて使う

撮影を続けるには、費用も気になります。

私はコストを抑えるために、大きな缶に入った長尺の白黒フィルムを使い、自分で必要な長さにして、詰め替え用のパトローネに装填していました。パトローネとは、35mmフィルムを収める小さな遮光容器のことです。

撮影の前から、すでに手仕事が始まっていました。

フィルムに傷をつけないように扱い、光にさらさないよう気を配る。撮り終えたら、今度は現像の準備をする。

なお、一般的な白黒撮影用フィルムは赤い暗室灯にも感光します。フィルムを現像タンクのリールへ巻く作業などは、完全な暗黒か、光を遮るダークバッグの中で行います。赤い灯りの下で作業できる印画紙とは、扱いが違います。

撮影、現像、引き伸ばし。それぞれに必要な準備があり、一枚の写真は、いくつもの手順の先にありました。

フィルム現像は、見えない像を待つ時間

フィルムをリールに巻き、遮光されたタンクに収めると、現像液を注ぎます。

ここからは、温度計と時計が頼りです。フィルムと現像液の組み合わせに合った温度や時間を確かめ、決めた方法で攪拌します。

タンクの中で、像がどうなっているかを見ることはできません。

手順を整え、その結果を待つ。暗室作業には、化学実験のような慎重さがありました。段取りや温度管理が仕上がりにつながる点では、料理を思わせるところもあります。

現像の後は、停止、定着、水洗いへと進みます。定着は、感光性の残る未現像のハロゲン化銀を取り除き、明るい場所で扱える像にする工程です。

処理を終えて取り出したフィルムに、コマごとの像が並んでいる。その光景にも、独特の安堵がありました。

引き伸ばし機の下で、もう一度写真を見る

乾燥したネガを引き伸ばし機にセットすると、今度は印画紙に写真を焼き付けます。

引き伸ばし機は、ネガを透過した光をレンズで投影する装置です。投影する大きさやピントを調整し、印画紙に光を当てます。

最初から一枚を仕上げるとは限りません。細長く切った印画紙などで露光時間を変えたテストを行い、仕上がりを確かめます。

どこまで画面に入れるか。暗いところに階調を残せるか。明るい部分が白く抜けすぎていないか。

必要に応じて、一部分に当たる光を減らす「覆い焼き」や、追加で光を当てる「焼き込み」も使います。撮影時に見た風景を思い返しながら、紙の上の表現を整えていく作業です。

ネガに写っているものを確かめながら、自分がその場で何を見ていたのかも、もう一度考えていたのだと思います。

白い紙に像が現れる、その先まで

露光した印画紙を現像液に入れると、像が浮かび上がります。

ただし、最も美しく見えた瞬間に慌てて引き上げ、定着することが、基本の仕上げ方ではありません。印画紙は、使用する製品と現像液に応じた時間・温度で十分に現像し、明るさは主に露光条件で調整します。像が濃すぎる場合には、露光などを見直して焼き直します。

魔法のように見えた瞬間も、確かな手順の中にありました。

現像を終えた印画紙は、停止浴、定着、水洗いへと進み、最後に乾燥させます。水洗いや乾燥の扱いは、樹脂で被覆されたRC印画紙と、紙を基材とするバライタ印画紙などで異なります。

像が出たから完成、というわけではありません。長く残すためには、その後の処理も大切でした。

流し台を流れる水を見ながら、仕上がりを待つ。その時間も含めて、一枚を作っていたのです。

写真を「育てる」という記憶

こうして出来上がった写真には、被写体だけでなく、そこへ至るまでの時間も重なっていました。

撮影するときの迷い。フィルムを扱う指先の感覚。温度計を見つめた時間。印画紙に最初の影が現れた瞬間。

そして、作業を支えてくださった大家さんご夫婦の優しさ。

写真そのものを見ても、そうしたことは写っていません。けれど、私にとっては、その一枚とともに残っています。

今は、撮影から仕上げまでの方法が大きく変わりました。私も、その便利さに助けられています。それでも、押入れの小さな暗室で過ごした時間は、写真を大切に扱う感覚の土台になっているように思います。

撮影した瞬間を、自分の手で確かめ、整え、残す。

私にとって、暗室作業は、写真を「育てる」時間でした。

巻末資料③：現像・引き伸ばしに使う薬品

薬品・処理液 使用する工程 主な役割・注意点
