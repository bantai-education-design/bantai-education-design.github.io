AIと学び

Windows 3.1から30余年――AIの登場で変わるパソコンの「当たり前」と、これからの学びの本質

私たちは、もうOSを意識しなくなるのだろうか

2026年11月25日　Ban.Tai Education Design

　私が初めてWindowsに触れたのは、Windows 3.1の時代でした。
それから30年以上の歳月が流れ、Windows 95、98、XP、7、10、そして現在の11へと、長い時間をパソコンとともに歩んできました。
途中には使いやすさに驚いたものもあれば、なかなかなじめなかったものもありましたが、一つだけずっと変わらないことがありました。

　それは、「パソコンを使うためには、Windowsという土台が必要である」ということです。

　電源を入れればWindowsが起動し、画面に並ぶアイコンをマウスで選び、文書を作成して保存し、印刷する。
あまりにも日常に溶け込んだ当たり前の光景だったため、私たちはいつしかWindowsそのものを意識することさえ少なくなっていました。

　ところが今、AIの登場によってその当たり前が大きく変わろうとしています。
2026年11月25日、ITmedia PC USERで「Windowsはもはや“ランチャー”になる？　Copilot新画面『Home』とローカルAI戦略が示すOSの未来」という記事を読みました。
長年Windowsに支えられてきた私にとって、それは少し寂しくもあり、それ以上に深い興味をかき立てられる内容でした。

　パソコンの役割が変わるとき、私たちの仕事や子どもたちの「学び」はどう変わっていくのか。
本コラムでは、30年余りの実体験と教育に携わってきた立場から、OSの現在地とこれからの人間とAIの関係について考えてみたいと思います。

1. そもそもOSは、何をしてくれていたのか

　まずは原点に立ち返り、「OSとは何か」を整理しておきましょう。
OSとはOperating System（オペレーティングシステム）の略で、パソコン全体を動かすための基本的な仕組みを指します。

　たとえば、私たちがWordで文章を書いている場面を思い浮かべてみてください。
キーボードから文字を受け取り、画面に表示し、作成した文書を記憶装置に保存する。
プリンターにつなげば印刷もできます。
こうした一連の仕事を、Wordだけで全部行っているわけではありません。
Windowsがキーボードや画面、記憶装置などを裏側で管理し、Wordが滞りなく働けるように支えているのです。

　学校に例えるなら、OSは校舎や教室、電気、水道といった設備を管理し、学校全体が安全に動くように整えている仕組みに近いと言えます。
その土台の上で、先生や子どもたちが日々の授業や行事を行っています。
校舎の配線や配管を普段から意識する人はあまりいませんが、それが止まれば学校の営みは成り立ちません。
OSもまた、普段は目立たない黒子でありながら、なくてはならない存在だったのです。

2. マウスとGUIの衝撃――「人間が機械に合わせる」時代の記憶

　Windows 3.1を使っていたころを思い出すと、今でも当時の新鮮な驚きがよみがえります。
画面に並ぶ絵をマウスで選び、クリックするだけで操作できる。
今では空気のように当たり前の操作ですが、当時はそれだけでもずいぶん便利になったと感じたものでした。

　それ以前は、キーボードから決まった命令を正確に打ち込まなければならない場面が多くありました。
一文字でも間違えればエラーが返ってくる世界から、絵や文字の並ぶ画面を見ながら直感的に操作できる世界へ変わったのです。
こうした仕組みをGUI（Graphical User Interface）と呼びます。
さらにWindows 95でスタートメニューが登場すると、ソフトを探して起動し、ファイルを開いて作業するというスタイルが一気に定着しました。

　しかし今あらためて振り返ると、この30年余りは、私たち人間が「パソコンの使い方を覚えること」に膨大な時間を費やしてきた歴史でもありました。
どのソフトを開き、どのメニューを選び、どこへ保存するのか。
機械のルールに合わせて人間側が手順を組み立てていくことが、これまでのパソコン操作の前提だったのです。

3. AIエージェントが変える「操作する相手」

　ところが、最近のAIはその前提そのものを静かに変えようとしています。
たとえば、パソコンの中にある写真を整理する場面を考えてみましょう。

　これまでであれば、フォルダーを開き、写真を確認し、名前を変更し、別のフォルダーへ移動するという作業を、人間が一つひとつ手作業で行わなければなりませんでした。
ところがこれからのAIには、次のような自然な言葉で頼めるようになっていきます。

　「昨年の運動会の写真を探して、学年別に整理してほしい」

　するとAIは必要なファイルを探し出し、内容を調べ、整理する手順を自ら考えます。
そして許可された範囲の中で、実際の移動や分類といった操作まで進めることができるようになります。

　このような仕組みが「AIエージェント」です。
従来のAIが質問に答える「相談相手」を中心としていたのに対し、AIエージェントは与えられた仕事を自律的に「実行する」方向へと進んでいます。
もちろん、現在のAIがいつでも正確に操作できるわけではなく、すべてのパソコンで同じ機能が使えるわけでもありません。
それでも、「人間がパソコンの操作方法を覚える時代」から「パソコンが人間の言葉を理解して仕事を進める時代」へと向かう大きな転換点に、私たちは確かに立っています。

4. 「見えなくなるWindows」とハイブリッド・インテリジェンス

　今回の記事でとくに印象的だったのが、Microsoftが発表したCopilotの新しい画面「Home」です。
従来のWindowsでは、スタートメニューからソフトを探して起動するのが基本でした。
それに対し新しいHomeでは、今日の仕事を確認したり、AIに作業を頼んだり、複数の仕事をまとめて進めたりすることが重視されています。

　つまり、「どのソフトを開くか」よりも、「自分が何をしたいのか」が先に来る設計へと発想が大きく転換しているのです。
表に見える窓口がAIへと移っていくにつれ、OSは表舞台から一歩引いていくのかもしれません。
ただし、OSが不要になるわけではありません。
AIが仕事をするためにも、ファイルを管理し、プログラムを動かし、安全性を守る土台は不可欠です。
表に立つのはAIで、裏側で静かに支え続けるのがWindows――今後はそんな役割分担がいっそう強まっていくのでしょう。

　もう一つ押さえておきたいのが、AIの働く場所の変化です。
これまでChatGPTなど多くのAIは、インターネットの向こう側にある高性能なコンピューター、すなわち「クラウド」で動いてきました。
一方これからは、自分のパソコンの内部でもAIを動かす仕組みが広がっていきます。

　簡単な文章の整理やファイルの分類は手元のパソコンの中で素早く行い、より難しい調査や分析が必要になればクラウドの高性能なAIを利用する。
このように手元のパソコンとクラウドを使い分ける考え方を、Microsoftは2026年10月7日の公式ブログで「ハイブリッド・インテリジェンス」と呼んでいます。
仕事の内容によってAIの働く場所を選ぶことで、処理速度や費用、情報の安全性などのバランスをきめ細かく調整しようとしているのです。

　もっとも、パソコン内で高度なAIを動かすには相応のハードウェア性能が必要になります。
最新機種への買い替えが誰にとっても簡単なわけではありません。
だからこそ、少し古いパソコンであっても、クラウドのAIを活用すれば十分に便利な仕事ができるという事実は、今後も忘れたくない大切な視点です。

5. 便利になるほど増える心配――人間の主導権と「安心」の設計

　私は、AIによってパソコンが使いやすくなることに大きな期待を寄せています。
しかし同時に、便利さが増すほど気になることも増えていきます。

　AIがファイルを探し、整理し、削除や送信までできるようになるとしたら、間違えたときはどうなるのでしょうか。
大切な写真を消してしまうかもしれませんし、別の人に送ってはいけない文書を送ってしまう恐れもあります。
学校の仕事であれば、子どもたちの個人情報という極めて重い情報も関係してきます。

　だからこそ、AIがどこまで操作できるのかを、最終的に人間が決められることが何より大切だと思います。
AIが勝手に何でも実行するのではなく、重要な操作の前には必ず人間へ確認する。
何を実行したのか記録が残り、間違えたときには確実に元に戻せる。
そして、AIを使いたくない人は使わずに、従来の方法で操作できる選択肢が守られている。
そうした仕組みが不可欠ではないでしょうか。

　MicrosoftもAIの操作領域を通常の作業環境から分離するなど、安全性を重視した技術を進めています。
便利さを競うだけでなく、誰もが安心して使える土台を大切にしてほしいと強く願います。

6. パソコンを「学ぶ」ことの意味が変わる――教育との深いつながり

　教育に関わってきた私には、今回の変化を通してもう一つ深く考えたいことがあります。
それは、パソコンを「学ぶ」ことの意味の変化です。

　これまでパソコンの学習と言えば、キーボードの使い方、ファイルの保存、ソフトの起動、文書作成や表計算の操作などが中心でした。
これからもこうした基本操作は必要でしょう。
しかし、AIが操作を肩代わりしてくれる時代には、手順を覚えるだけの学習では明らかに足りなくなります。
代わりに、次の四つの力がこれまで以上に大切になるのではないでしょうか。

　第一に、自分が何をしたいのかを言葉で明確に説明する力。
AIは人間の言葉を手がかりに動くため、自分の頭の中にある目的や課題を言語化する力が欠かせません。
第二に、AIが出した答えや処理結果を自らの目で確かめる力。
もっともらしい出力であっても、事実や前提に誤りがないか検証する姿勢が求められます。
第三に、間違いや違和感に気づき、指示を練り直したり手作業で修正したりする力。
そして第四に、何をAIに任せ、何を自分の責任で判断するのかを見極める力です。

　AIを使うということは、人間が考えなくてよくなることではありません。
むしろ操作の手間から解放されるからこそ、「自分は何をしたいのか」「この結果は本当に正しいのか」と、自分の頭で深く考えることが求められるようになります。
私はここに、テクノロジーと教育との大きなつながりを感じています。

7. おわりに――30余年お世話になったWindowsのこれから

　Windows 3.1のころ、パソコンに向かう私はまず操作方法を覚えなければなりませんでした。
今は、AIに言葉で相談しながら文章を書き、資料を調べ、プログラムをつくることまでできます。
30年以上の間に、本当に遠くまで来たものだと思います。

　けれども、パソコンが人間の言葉を理解するようになったとしても、人間が判断する責任までなくなるわけではありません。
便利さのために、人間が操作や意思決定の主導権を失ってしまうようでは困ります。

　長年お世話になったWindowsには、これからも安心して働ける土台であってほしいと願っています。
私たちがOSを意識しなくなるほど、裏側では正確に、安全に、静かに働き続けていてほしいのです。
親しんできたWindowsがまた新しい姿へと変わろうとしていることに少し寂しさも覚えますが、私はこの変化をしっかりと見届けたいと思います。

　そして何より、パソコンが人間に合わせてくれる時代になっても、人間が自らの頭で考えることの大切さだけは、これからも決して変わってほしくないのです。
