Smart Resume Generator

スマート履歴書ジェネレーター

履歴書・職務経歴書・送付状の3点を、1つの画面で仕上げられるWindows用アプリです。厚生労働省の履歴書様式例に沿ったテンプレートを標準搭載し、表裏2ページPDFやコンビニ印刷向けのA3見開きPDFで出力できます。

対応OS：Windows 10 / 11。インターネット接続は不要です。10日間無料で試用でき、試用中は印刷物とPDFに SAMPLE の文字が入ります。ライセンスキー（1,980円）で SAMPLE 表示が消えます。

Overview

応募書類づくりを、ひとつの画面で。

左側で入力しながら、右側のプレビューで完成形をそのまま確認できます。氏名・住所・学歴・職歴・資格を一度入力すれば、履歴書だけでなく職務経歴書と送付状にも使われるので、同じことを何度も書く必要がありません。

年の表記は西暦と和暦をワンタッチで切り替えられ、生年月日から満年齢や入学・卒業年も自動で計算します。手書きで起こりやすい年の書き間違いを防げます。

証明写真（JPG / PNG）を読み込み、写真枠の中で位置と大きさを調整できます。入力した内容はパソコンの外に送信しません。

Features

主な機能

書

厚生労働省様式の履歴書

性別欄は任意記載、通勤時間・扶養家族の欄がない現在の標準の形です。転職用、アルバイト用（A4×1枚）、旧JIS様式にも切り替えられます。

職

職務経歴書・送付状

職務要約、会社ごとの経歴と実績、スキル、資格、自己PRをA4にまとめます。送付状は会社名と応募職種から整った文面を作ります。

刷

表裏PDF・A3見開きPDF

表面と裏面を正しい向きの2ページPDFで作成。A3見開きPDFは、コンビニでA3またはB4に縮小して印刷し、真ん中で折ると市販の履歴書と同じ形になります。

入力・編集機能

  • 厚労省様式 / 転職用 / アルバイト用 / 旧JIS様式の切替
  • 年の表記を西暦 / 和暦で切替（入力は西暦のまま）
  • 生年月日から満年齢と入学・卒業年を自動計算
  • 学歴 / 職歴 / 資格の行を必要なだけ追加
  • 志望動機・自己PRの例文アシスト（インターネット不要）
  • 証明写真の読み込みと位置・大きさの調整
  • フォント・文字サイズ・ふりがな形式の切替
  • サンプル読込で記入例を確認

出力・保存

  • 表裏2ページPDF（両面印刷はPDFの印刷画面で設定）
  • A3見開きPDF（コンビニ印刷向け）
  • 表面だけ / 裏面だけの印刷にも対応
  • 職務経歴書PDF・送付状PDF
  • 入力内容をパソコン内に保存し、次回は続きから
Highlights

特色

  • Windows 10 / 11 用。インストール不要で、展開したフォルダーのexeを起動するだけです。
  • 入力・写真配置・保存・PDF作成・印刷はすべてオフラインで動きます。
  • 氏名や住所は一度入力すれば、履歴書・職務経歴書・送付状のすべてに使われます。
  • 和暦変換や年齢・入学卒業年の計算を自動で行い、書き間違いを防ぎます。

体験版とライセンスキー

体験版は10日間すべての機能を使えます。試用中と未認証のときは、印刷物とPDFに SAMPLE の文字が入ります。BOOTHでライセンスキー（1,980円）を購入し、アプリに入力すると SAMPLE の文字が消えます。

AI設定（任意）について

例文アシストはインターネットなしで使えます。ご自身の Gemini API キーを登録した場合に限り、例文の代わりにAIが文章を作成し、そのときだけ入力したキーワードが Google に送信されます。履歴書の氏名や住所は送信されません。
