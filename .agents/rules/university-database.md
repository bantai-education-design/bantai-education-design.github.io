# University database rules
Applies to `tools/university-database/`.
- Do not invent missing university statistics, credentials, photos, historical details, or access information.
- Distinguish official source values from missing and unverified values.
- Preserve existing photos and the owner/admin registration workflow unless specifically approved.
- Validate linked records, filters, detail pages, mobile layout, and existing navigation after data or UI changes.
- Prepare a pull request; merge only after checks and required human approval.
