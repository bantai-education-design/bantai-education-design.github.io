# Editorial and book presentation rules
Applies to `columns/`, `books/`, `book2/`, and related editorial listing data.
- Preserve approved manuscripts, covers, illustrations, and previously accepted layouts; change only requested areas.
- Never use Markdown bold markers in published Japanese editorial text. Do not scan code syntax as if it were prose.
- Follow `GEMINI.md` for Japanese-only image lettering and note curation conventions.
- Check thumbnail/title readability, metadata, GA4, sitemap, navigation, and mobile layout when affected.
- Do not change live purchase links to fabricated or inactive URLs; preserve pending-publication states.
- Prepare a pull request; merge only after checks and required human approval.
